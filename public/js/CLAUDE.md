# public/js — 觸發卡(本目錄 = 客戶端 60 支模組 + 全遊戲平衡數值)

> 這張卡刻意很短(會自動載入)。真正的模組層情境住 [`.claude.md`](.claude.md)(134KB,**手動開**),依領域分節。

**動本目錄任一支之前 MUST 做的三件事**

1. 開 [`.claude.md`](.claude.md) §1 **檔案職責地圖**確認這支的邊界與關係,再讀 §2 對應領域的模組級地雷(A 權威結算 / B 地景生成 / C 模型動畫渲染 / D FPV HUD 小地圖 / E 觸控陀螺版型 / F 網路單機預建)。
2. 到根 [`/CLAUDE.md`](../../CLAUDE.md) §2.1 的目錄查你要動的主題屬於哪一支 [`/.claude/rules/seams-*.md`](../../.claude/rules/),**讀那一支的全文**;查不到就 `grep -rn "<關鍵詞>" .claude/rules/`。
3. 動完 **MUST** `node tools/audit_client_syntax.mjs`(根 §5.4 ㋖)—— 半數模組要 CDN 的 three,沒有任何離線稽核 import 得了它們:語法錯誤會讓整套回歸驗證照樣全綠,而真人一開頁面就是白畫面。

**兩條最容易被忘記的**

- `data.js` 是**全遊戲平衡數值唯一真相**,伺服器直接 import 這支客戶端檔 ⇒ 改它幾乎等於改全部,根 §5.4 ㋔ 的相鄰稽核要整批跑。
- 確定性:散布路徑 MUST NOT 用 `Math.random()`,而**新增世界內容一律要問「這一段消耗了幾枚共享 `rnd()`」**(根 §2.3 / A4)—— 多抽一枚就把後面每一株植被的佈局整條推移,而畫面上只表現成「整張圖變了」,沒有任何錯誤訊息。
