# public/js — Module Layer (client modules + balance values)

> Tier-3 module context for use with root `AGENTS.md` (Tier-1), `.claude/rules/`
> (Tier-2), and offline audits (Tier-4). Contents: file responsibility map (SSOT) +
> module-level hard constraints.
>
> Binding constraints:
> 1. `data.js` is the sole balance-values source of truth, imported directly by the server. Changing it changes everything; run adjacent audits together.
> 2. Determinism: scatter paths MUST NOT use nondeterministic randomness. New world content keeps zero shared `mulberry32` consumption; appearance varies via coordinate-hash seeds.

## 2. Module-Level Hard Constraints (Gotchas)

### A. Authority settlement and combat numbers (`data.js` / `game.js` / `sim.js`)
1. Solo serialization deep-copies: `_serializeEnt` MUST NOT leak authority object references; nested fields (e.g. `upg`) are spread-copied so optimistic client updates cannot pollute server state.
2. Coating double-sided blocking: penetrating rays and grenade landing go through `_layerHitT` (terrain plus obstacle-box/roadway/roof slabs). Tunnel roofs have solid thickness `[tn.ceil, tn.roof]` blocking shells on both faces.
3. Halo vs damage footprint: range halos light only for units that would actually take damage when the aimed target is in range. Blast ignores LOS and range by design (A11 diffraction); fan/pierce have no single-entry gate.
4. Range tolerance with muzzle-origin standard: the server gate uses `RANGE_TOL` (x1.25); server-initiated selection (fan/pierce) uses the honest bound with the muzzle as origin.
5. Height frankness with high-ground suppression: height differences compare inside the absolute elevation frame, never field altitude as relative height; high ground gains range and evasion but pays a suppression cost after being hit.
6. Range convergence with movespeed compression: blast weapons converge inside the same site's two-tower spacing and refunded firepower redistributes by geometric mean; movespeed compression preserves order with a fixed geometric midpoint.
7. Shield/armor split: buildings take no multipliers (A34); shield and armor route only through `data.js shieldSplit()` with exact overflow refund; no end writes its own criterion.
8. Minor-cast chanting with forced cast on hit: minors chant on the body with timing from the order-preserving `skillCastTime()`; hits force partial settlement by the squared chant ratio $(t/T)^2$. Ultimates deliver via works carriers and escort fleets.

### B. Terrain generation and scene layout (`terrain.js` / `biomes.js` / `ground.js` / `siteplan.js` / `edgewall.js`)
1. Structure footprints MUST NOT overlap: functional blocks test true footprints (oriented boxes or bounding circles) with prop footprints measured from solid `detailR`; no clipping.
2. Portal carving trims drawing only: `punchPortalHoles` deletes draw indexes without touching collision or elevation; corridor tests use 2D SAT matrices so no terrain wedge survives at portals.
3. Open-tunnel vs underpass sections: open tunnels keep one column side open with the side drop read from solid cliffs; underpass sunk sections re-verify full width and fall back to open cuttings where structures cannot hide.
4. Roadbed grading and joints: dry corridors grade flat across, structure joints feather with `ROAD_FLARE_M` tapes; traffic width and paint width stay on separate tracks.
5. Landscape puzzle with zero shared RNG: blocks, public facilities, landmarks, flags, and boundary walls consume zero shared `mulberry32` so they never shift the vegetation/building sequence.

### C. Body modeling, rigs, and cel rendering (`forge/` / `toon.js` / `postfx.js` / `locomotion.js` / `morphrig.js`)
1. Polyhedron-part forging: per-unit files assemble only from the `forge/geo.js` vocabulary; hard-edge geometry carries a smooth `userData.outlineGeo` copy.
2. Morph-rig derivation: both forms share the same parts with morph motion back-solved from dual-form rig-matrix TRS deltas; no hand-written performance timelines.
3. Cel shading with material encapsulation: dark sides keep a brightness floor with luminance-neutral hue shifts; soft matter (grass/trees/flags) outlines follow the alpha contract with pure vertex-sway motion.
4. Post pipeline with wipe transitions: world outlines stay a single pass; wipes insert between grade and FXAA with outline fade anchored to `scene.fog`. No backticks inside GLSL comments.

### D. Interface, input, and audio (`help.js` / `mobile.js` / `ctrlmode.js` / `audio.js`)
1. Touch hardening decoupled from layout: page-level mis-touch guards (pinch-zoom/long-press selection) bind the hardware `touch-dev` flag, not the `touch-ui` layout style.
2. Host-finalized control mode: the host locks one room-wide control mode; clients MUST NOT override it.
3. Audio tiers with resident beds: ambience and movement beds are resident stems cross-faded by gain, movement tied to the animation weight vector, never retriggered stepwise. Samples are strictly CC0.
