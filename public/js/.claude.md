## 3. 近期技術債與地雷(新 → 舊;動到相鄰程式前 MUST 讀完)

**07-18 鐵軌高度一致性 + 平交道**(`biomes.js buildRails`):OSM 把連續鐵軌切成「地面 way + `bridge` way」時,舊版對整條 way 套固定 lift → 接點瞬跳 8m(看起來斷掉)。改**逐頂點 lift**:高架段只在「未接續另一段高架」的端點沿 `RAIL_RAMP`(55m)爬升緩坡回地面,接續高架處(共用端點 `ekey` 量化計數 ≥2)保持全高。端點連續性靠**世界座標 0.5m 量化 key**(共用 OSM 節點 → 同座標 → 同 key),**MUST NOT** 改回整條固定 lift。橋墩改吃 `pierPts`(過矮 <2.5m 略過,免爬坡段殘樁)。平交道 = OSM `railway=level_crossing` 節點(fetch 已加 `out 40`),`buildLevelCrossings` 取最近**地面**軌切線定方位(高架/隧道段附近 >30m 略過),遮斷器**抬起**狀態(不擋兵線、無碰撞)。列車 `trainDriver` 仍用 `Math.random` 起始位置(既有、純表現,不動)。
