# public/js — Client Principles & Boundaries

> Scope: principles and boundaries only. No methods, no workflows, no commands.
> Global principles live in root `AGENTS.md`.
> Nothing in this file restricts skill selection or skill usage.

## Principles

1. **Server-authoritative**: client NEVER settles authority state first; client ballistics are presentational only.
2. **Single numeric source**: `data.js` is the sole balance-values source, imported directly by the server. Derived values MUST NOT be hand-written.
3. **Determinism**: scattered layouts MUST NOT use `Math.random()`; new world content MUST NOT disturb the shared `mulberry32` sequence.

## Hard Boundaries

- `data.js`: sole balance source. MUST NOT hard-code range / damage / price elsewhere.
- `codex.js`: sole character/body file-format definition; content lives in `lore.js` / `mecha.js`, numbers live in `data.js`.
- `mecha.js`: structured prototype layer derives from `visual`. MUST NOT hand-write total height or copy faction/type numbers.
- `forge/roster.js`: classification is purely derived. MUST NOT hand-write name lists.
- `botPolicy.js`: generated output only. MUST NOT hand-edit.
- `venueGrid.js` / `venueLanes.js` / `venueText.js`: offline-baked outputs only. MUST NOT hand-edit.
- `rng.js`: sole deterministic-RNG seam (`mulberry32`). Pure algorithm, zero imports.
- `lore.js`, `climb.js`: client-only. Server MUST NOT import them.
- `tip.js`, `npcicon.js`, `cutin.js`, `dialogue.js`, `worldtext.js`: presentation-only. MUST NOT affect simulation.
- `help.js`: sole game-help / control-guidance seam; device-branch strings MUST NOT be reimplemented in `main.js`.
- `game.js` / `terrain.js` / `ground.js`: raycast hits units only; terrain uses analytic rays. MUST NOT feed `terrain.mesh` into the raycaster.
- `edgewall.js`, `vehicles.js`, `wildlife.js`, `roadgrid.js`, `pedestrian.js`, `field.js`, `siteplan.js`: zero shared-RNG consumption; appearance differences come from coordinate-hash seeds.
- `postfx.js`: single-pass world outlines; released resources on teardown.
- `audio.js`: samples strictly CC0.
