# public/js — 模組層維護指南 (客戶端模組與平衡數值)

> **本檔定位**: 四層情境系統的**第 ③ 層 (模組層)**，搭配根目錄 `CLAUDE.md` / `AGENTS.md` (第一層)、`.claude/rules/` (第二層) 與離線稽核 (第四層) 使用。
> 本檔收錄：**檔案職責地圖 (Single Source of Truth)** + **模組級地雷與不可侵犯之硬約束**。
>
> ⚠️ **重要約束**:
> 1. `data.js` 為**全遊戲平衡數值唯一真相**，伺服器直接 `import` 此檔。修改其數值幾乎等同修改全局，相鄰稽核須連帶執行。
> 2. 確定性原則：場景散布嚴禁使用 `Math.random()`，新增世界內容必須維持零共享 `mulberry32` 消耗，外觀差異由座標雜湊自帶種子。

## 2. 模組級硬約束與地雷 (Gotchas)

### A. 權威結算與戰鬥數值 (`data.js` / `game.js` / `sim.js`)
1. **單機序列化深拷貝**: `_serializeEnt` 嚴禁洩漏權威物件參考，巢狀欄位（如 `upg`）必須展開複製，避免客戶端樂觀更新直接污染伺服器狀態。
2. **塗層雙面阻擋**: 射線貫穿與榴彈落點判定走 `_layerHitT`（結合地形與障礙盒/路面/頂板）。隧道頂板具實體厚度 `[tn.ceil, tn.roof]`，站在頂板上向下或向上射擊皆具完整物理阻擋。
3. **範圍光暈與傷害足跡**: 範圍光暈僅在「準星目標在射程內被擊中時、會同時受到傷害之單位」點亮。爆炸傷害不吃 LOS 與射程（A11 繞射物理），扇形與貫穿不依賴單一入口閘。
4. **射程容差與球心標準**: 伺服器驗證閘門使用 `RANGE_TOL`（×1.25）；伺服器主動選敵（如扇形/貫穿）走誠實界，球心恆為槍口位置。
5. **高度制空與高地壓制**: 高度差計算全程在絕對高程框內比對，嚴禁拿場地海拔當相對高差；高地享有射程與閃避加成，同時受擊後觸發高地壓制代價。
6. **攻擊範圍收斂與移速壓縮**: 爆炸武器攻擊範圍受限於同塔位雙塔間距，收斂之火力由幾何平均重分配返還；移速壓縮嚴格保序，幾何中點維持不動。
7. **護盾裝甲分軌與建築加乘移除**: 建築加乘全面移除；護盾與裝甲剋制拆分僅走 `data.js shieldSplit()`，溢出傷害精確折算，嚴禁各端自寫判據。
8. **小招本體詠唱與受擊強制施展**: 小招移除載具，改為本體詠唱機制，時間由 `skillCastTime()` 保序映射；受擊時依已詠唱時間比例平方 $(t/T)^2$ 強制結算效果。大招維持工事載具遞送與跟隨輔助機隊。

### B. 地形生成與場景佈局 (`terrain.js` / `biomes.js` / `ground.js` / `siteplan.js` / `edgewall.js`)
1. **結構足跡互不重疊**: 功能性區塊（球場、停車場等）重疊判定必須吃真實足跡（有向盒或外接圓），擺件足跡量測實體幾何 `detailR`，嚴禁穿模。
2. **打洞與幾何整理**: 隧道洞口打洞 (`punchPortalHoles`) 僅刪除繪製索引，不修改碰撞與高程；走廊判定使用 2D SAT 矩陣，避免洞口殘留地形楔片。
3. **明隧道與地下道剖面**: 明隧道單側開柱開放，側向地表落差掃描由實體山壁判定；地下道下沉剖面全寬重驗，藏不住結構之段落退回露天路塹。
4. **道路路基整平與接合**: 道路乾地走廊橫向平整，結構接合處以 `ROAD_FLARE_M` 漸縮帶貼合，通行寬度與塗裝寬度嚴格分軌。
5. **地貌拼圖與零共享亂數**: 街廓、公設、地標、國旗與邊界牆一律零共享 `mulberry32` 消耗，避免擾動全圖植被與建築生成序列。

### C. 機體建模、骨架與著色渲染 (`forge/` / `toon.js` / `postfx.js` / `locomotion.js` / `morphrig.js`)
1. **多面體零件鍛造**: 逐機定義檔僅使用 `forge/geo.js` 語彙拼裝，硬邊幾何必須攜帶 `userData.outlineGeo` 平滑副本。
2. **變形骨架推導**: 兩形態使用相同零件，變形過程由雙形態骨架矩陣 TRS 差分反推，嚴禁手寫演出時間軸。
3. **賽璐璐明暗與材質封裝**: 暗面具備亮度地板，色相偏移維持亮度中性；軟性物質（草/樹/旗）細勾線走 Alpha 契約，擺動採純頂點位移。
4. **後製管線與 Wipe 轉場**: 全場描邊單一 Pass；轉場 Wipe 插入於 Grade 與 FXAA 之間，勾線淡出錨定於 `scene.fog`。GLSL 註解內嚴禁出現反引號。

### D. 介面、輸入與音效 (`help.js` / `mobile.js` / `ctrlmode.js` / `audio.js`)
1. **觸控硬化與裝置解耦**: 頁面級防誤觸（防止捏合縮放/長按選字）必須綁定硬體屬性 `touch-dev`，而非版型樣式 `touch-ui`。
2. **操作方式房主定案**: 房主鎖定操作模式後全房一致，客戶端嚴禁自行覆寫。
