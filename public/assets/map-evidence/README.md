These are cropped numeric classification rasters, not rendered satellite images.
Each JSON preserves the source lattice and source URL/header/block/pixel digests.
The manifest derives from VENUES; preparation captures the union of real battle
frames and a halo. Software licensing does not replace this source-data license.
Generation and audit commands live in package.json.
