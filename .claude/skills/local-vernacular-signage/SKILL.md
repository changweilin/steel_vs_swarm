# 在地日常生活文字(Local Vernacular Signage)

**主張:一塊招牌讓場景變成一個「地方」,靠的不是畫得多精緻,是上面那行字剛好是
這裡的人每天會讀到的字。**

方法來源:sakura-crossing(`C:/Users/user/Documents/study/sakura-crossing`)——
`src/core/textures.js` 的 134 個文字生成器、`SHOPS`/`ONSEN` 兩張租戶表,以及
`CLAUDE.md` 記錄的踩坑。該世界零二進位素材,所有字都是 Canvas2D 當場畫的。

**分工**:這支 skill 管**寫什麼**;**怎麼畫**(canvas/快取/字級自適應/貼圖上機)走
`procedural-canvas-textures`。兩支都要看,漏掉任一支的結果分別是「畫得很漂亮但讀起來
像素材庫」與「內容對但糊成一條」。

## 一、六條方法

### 1. 地名主幹(toponym spine)—— 全世界從一個詞長出來

sakura 的整座鎮從 **ひばり(雲雀)** 長出來,原文出現 263 次、橫跨 32 個檔案:

> ひばり台(町名)/ ひばり山(山)/ ひばり湖(湖)/ ひばり橋(橋)/ ひばり用水路(水路)/
> ひばりマート(超商)/ ひばり不動産 / ひばり輪業 / ひばり台内科 / ひばり堂(文具)/
> ひばり台土地改良区(管理機關)

同一個詞反覆出現 = 這些東西**屬於同一個地方**;各叫各的 = 一堆素材擺在一起。

- 主幹之下再分**行政層級**(一丁目/二丁目/四丁目…)與**功能地名**
  (学校前通り = 學校前那條路、川端の道 = 河邊那條路)。功能地名不必好聽,要**好懂**。
- **有真實圖資時,主幹不用發明**:圖資裡出現頻率最高的那個地名(行政區/河/山/幹道)
  就是主幹。發明一個新的反而把在地感洗掉。

### 2. 三層文字(name / everyday / roman)

一塊商業招牌至少三個欄位,少一個就掉一層可信度:

| 欄位 | sakura 例 | 作用 |
|---|---|---|
| 主名 `t` | `青空商店` | 這是誰 |
| **日常副行 `s`** | `たばこ ・ 氷 ・ 弁当` | **這一行才是「日常生活」** |
| 拉丁副名 `en` | `AOZORA STORE` | 視覺節奏 / 次要層次 |

**日常副行寫的是「這裡真的在發生什麼」**:賣什麼(`こしょ かいとり` 舊書收購)、
幾點到幾點(`あさ六時 - よる十一時`)、這週輪誰掃地(`町内会 / そうじ当番`)、
哪天有市集(`野菜市 / 毎週日曜`)。

> 沒有副行的招牌只是一個名字;有副行的招牌是**有人在裡面上班**。

### 3. 語域隨物件類別走(register)

一塊牌子讀起來是什麼機構,由**欄位結構**決定,不是由字體或顏色決定。
sakura 的閘門牌註解直接把這件事寫出來:「這是全世界唯一一塊讀起來是**基礎設施**
而不是商店或警語的牌子 —— 一個工號、一個閘號、一個維護機關的名字。」

| 類別 | 欄位結構 | sakura 實例 |
|---|---|---|
| 商業 | 名 + 商品 + 時間 | `らーめん 一心 / しお しょうゆ みそ` |
| 基礎設施 | 工號 + 編號 + 管理機關 | `第二分水門 / 管理番号 ひ-一四 / 開度 全閉 / ひばり台 土地改良区` |
| 警告 | 一個大字 + 一句白話 | `危険 / ふかい水路です` |
| 宗教 | 名 + 儀節 | `参拝の作法`、繪馬、籤 |
| 交通 | 目的地 + 距離 + 時刻 | 站牌 / 路線圖 / 時刻表 |
| 政府公告 | 標題 + 日期 + 發文單位 | `町内会` 佈告、`ごみ` 收運日 |
| 水文 | 水位刻度 + 設施名 | `量水標`、`ひばり用水路 呑口 / 第一号 暗渠` |
| 風景解說 | 地名 + 標高/距離 + 一段來歷 | `眺望案内`、指路柱上的**真實距離** |

**把基礎設施寫成商業語域(或反過來)= 整個世界的公信力當場消失,而畫面上看不出
哪裡錯。** 這是本 skill 最貴的一條。

三條延伸,全部來自 sakura 的實作註解:

- **視覺語域也跟著類別走**:住宅區的診所/藥局/洗衣店是「近白底 + 一條細色帶 +
  用那條色帶的顏色寫字」—— 沒人為了它們特地跑一趟,所以它們不打廣告;老店則刻意
  **低對比**(粉化的漆、泛黃的底),那才是「舊」讀起來的樣子。高彩度大字是觀光/
  促銷語域,掛錯類別跟寫錯字一樣毀公信力(「會喊叫的診所是沒人信任的診所」)。
- **語意要對到構造**:進水口掛攔污柵、出水口不掛(「出水口裝柵是胡說」);同一條
  水路兩端是兩種年代兩種構造。牌子上的機構分工也要對 —— 營運機構的名字只出現在
  **工事牌**上,不出現在每一塊牌上,克制本身就是語域。
- **牌上的數字一律量自世界**:指路柱寫真實步行距離、展望台方位盤寫實測方位角、
  標高牌寫該點真實高程。可以被玩家驗證的數字才讓場景變成地方;編出來的數字被抓到
  一次,整個世界的字都不再被相信。

### 3-b. 一景一物的敘事克制

一支站牌**沒有**車停在旁邊,說的是「車正在別處跑」—— 比停一台車更有敘事。同理:
空著的停車格旁邊有一台車、準備中的祭典場、留言板上過期一週的告示。**缺席是語料的
一部分**,不要把每個容器都填滿。

### 4. 一鎮一家(one of each)

sakura 為此**多做了四塊招牌**,理由寫在原始碼註解裡:重用最接近的既有招牌,會把
「同一家文具店」同時放在四百公尺外的另一條街上 —— 一個鎮只有一家。

> 資料層 MUST 有**去重帳**:抽過的名字不再抽。連鎖店是例外,而例外要有名字
>(掛 `chain: true`),不能靠「反正看不出來」。

**發明的名字要記帳**:虛構世界的每一個專名(店名/橋名/路名/機關名)住在一張
**只准 append 的總表**裡。這張表同時是去重帳、主幹覆蓋率的計數來源、與「不撞真實
品牌/真實地名」的審查點 —— sakura 的 NEXT.md 逐輪把新名字補進同一張清單,
漏記的名字就是下一輪重複命名的來源。

### 5. 文字表與版面分離(one layout, N tenants)

`SHOPS` 是一張資料表(`bg/bar/fg/t/s/en`),`shopFascia()` 是**一個**版面函式。

- 新增一家店 = 加一列資料,**不是**複製一個繪製函式。
- 版面改一次,全部租戶跟著改。
- 反模式:每家店一個 `drawXxxSign()`。第五家店開始版面就開始各自漂移,而且沒人會發現。

### 6. 寫得下才算數(fit before you write)

版面先算出每個欄位**有幾像素**,取字時就照那個上限挑。sakura 的註解把數字直接寫死:
右欄 246px ≈ 拉丁 13 字 / 全形 8 字,超過就被切在板邊。

**真實圖資的名字長度完全不受控**(`Sir John Soane's Museum`、`臺北市立圖書館北投分館`)
⇒ **在取字階段就按容量篩**,不是等到畫的時候縮到看不見。畫得下 ≠ 讀得到。

## 二、資料來源:真實圖資(OSM)

八個類別 —— 這八類覆蓋「一個人走在街上會讀到的字」的絕大多數:

| 類別 | OSM 來源 | 落到哪種物件 |
|---|---|---|
| 地名 `place` | `place=*`、`boundary=administrative` 的 `name` | 佈告欄抬頭、路標地名、風景牌 |
| 路名 `road` | `highway=*` 的 `name`/`ref` | 道路路標、街角牌 |
| 商家 `shop` | `shop`/`amenity`/`craft`/`office`/`tourism` 的 `name` | 建築招牌、廣告看板 |
| 宗教 `worship` | `amenity=place_of_worship`、`building=temple/church/mosque/shrine` | 廟埕告示、參道牌 |
| 交通 `transit` | `public_transport`/`railway=station`/`aeroway` | 站牌、方向牌 |
| 政府機關 `gov` | `amenity=townhall/police/fire_station/post_office/school/hospital` | 佈告欄、機關門牌 |
| 水文 `water` | `waterway`/`natural=water`/`water=*` | 水利牌、水位標、橋名牌 |
| 地形 `terrain` | `natural=peak/ridge/cliff/valley/beach`、`ele` | 風景解說牌、標高牌 |

**取名優先序**(一律**保留在地文字**,不要翻譯):
`name` → `name:<在地語>` → `official_name` → `ref` → `operator` → `brand`。
`name:en` 只當**拉丁副名**用,不當主名 —— 巴黎的牌子上寫英文就不是巴黎了。

**日常副行的來源**(仍然只用圖資有的東西,取不到就留白):
`opening_hours` / `cuisine` / `operator` / `ref` / `addr:street` / `ele` / `denomination`。
留白比亂編好(寧缺勿錯)。

**類別詞(「麵包店」「派出所」)需要在地語言**:只在**確定該語言寫法**的語系提供小詞表
(通常每類 3~4 個詞就夠),其餘語系一律退回「只用圖資原字串」。在巴黎的牌子上寫
`營業中` 比留白更糟。

## 三、陷阱(這些會渲染成「藝術選擇」,不會渲染成錯誤)

| 症狀 | 真因 |
|---|---|
| 招牌是一條糊掉的直立污漬 | **貼圖長寬比 ≠ 落地面長寬比**。sakura 的 `alleyPlate` 512×128 貼到 0.24×1.5 m 的柱面 = 25 倍橫向壓縮。動手前先比兩個 aspect |
| 從另一邊看是鏡像字 | `BoxGeometry` 每個面自帶 `udir` 且在負向面已經反轉過 —— 雙面牌**再**做一次鏡像才會壞。sakura 曾對全世界每一塊雙面牌做了這個「修正」 |
| 印刷面被柱子吃掉幾個字 | 牌面厚度 MUST > 它綁的那根柱子;雙面牌置中在柱上,單面牌貼在柱前 |
| 這個道具看不出正面 | **有開口/投入口/鍵盤/把手的那一面,就是有字的那一面**。全部放同一面 |
| 一整組道具埋在牆裡 | 「外側」的正負號搞反。**先確定街在哪一邊,再擺第一個**,最後一個用同一個數字檢查 |
| 走過去整個視野是一塊空白背板 | 立牌站在 2m 通道正中央。道具屬於路肩;齊眼高的東西 MUST 從**兩個方向**各看一次 |
| 幾十種變體全長一樣 | 快取鍵沒帶變體索引 |
| 兩個玩家看到不同招牌 | 挑字用了 `Math.random()`。文字挑選 MUST 走場景那條 seeded 亂數 |
| 世界看起來像廣告,不像地方 | 招牌上出現人像。sakura 的硬約束:海報、繪馬、招牌**都不出現人** —— 由環境承載敘事 |
| 幾百個 draw call | 每塊牌一個 mesh。同類招牌 MUST 走一張**圖集(atlas)+ 逐實例 UV**,單一 draw call |

## 四、驗證清單

1. **逐類讀一塊**:隨機抽一塊牌唸出來 —— 唸不出這是商店還是機關,就是語域錯了(§1.3)。
2. **兩側各看一次**:鏡像字只有從另一側看得出來。
3. **去重帳**:同一場地不得出現兩塊同名招牌(連鎖除外,且要有旗標)。
4. **最長名字**:拿語料裡最長的那個名字實際排一次版,要能讀完。
5. **主幹覆蓋率**:數一數主幹地名在全世界出現幾次。個位數 = 這些東西還不屬於同一個地方。
6. **決定性**:同一顆種子跑兩次,每塊牌的字**逐字元相同**。
7. **零字場地**:圖資全空(離線/沙漠)時仍要出得了場 —— 退回不含專名的通用牌面,
   **不要**退回亂碼或英文佔位符。
