# §2.1 G — World Content (single seams)

> Layer 2: full definitions. Principles live in root `AGENTS.md`; assertion details live in audit script headers (layer 4).

| Topic | Single seam | Constraints | Guards |
|---|---|---|---|
| Urban plan | `siteplan.js` urban/civic blocks, `planBlocks()`, `roadFaceRy()` | MUST align building lines, not centers; MUST zone civic land before lots; MUST NOT register open ground as blockers; orientation reads through one function only; zero shared randomness. | `audit_siteplan` |
| Vehicle catalog | `vehicles.js makeVehicle()`, `vehicleBox()`, part bounds | Zero-import pure function with caller-injected variance; host-declared fit box separated from catalog-declared shape; trim and hardware derive from spec, MUST NOT hand-write per-model values; nose faces one axis at the footprint-center ground origin; body-plus-cabin collider stack registered. | `audit_vehicle_spec`, `audit_object_joints` |
| Recess and sightline | `vehicles.js RECESS`/`makeRecess()`, `standEyeM()`/`vehicleSight()` | Recesses build additively without moving mass; minimum recess depth enforced; eye height injected, MUST NOT hard-code it. | `audit_vehicle_spec` |
| Wildlife flocks | `wildlife.js flockSeed()`, `planFlockRoutes()`, `flockStep()` | Zero-3D with directly testable behavior; zero shared randomness via coordinate-hash seeds; friction derives from the single damping seam; anchors water-shore then grove then landmark, MUST NOT anchor tactical lines; omit the flock when unanchored; shared wind clock. | `audit_wildlife` |
| Crown shyness | `siteplan.js CROWN`, `crownGap()`, `planShyGrove()` | Crown radius derives from the parts table; shrink crowns before abandoning slots; sampling separated from rules with zero randomness in rules. | `audit_siteplan` |
| Ground carpet color/pattern | Carpet lot/sampling helpers, color roster | Style picks quantize to lots so one lot holds one style; adjacent same-color cells vary on a shared base; out-of-bounds skirts mirror inside with no new draw calls. | `audit_ground_tile` |
| Ground drape lift | `ground.js SAG`, `groundSagAt()`, drape helper | Pure function of position with bit-identical shared vertices; zero on flat ground; symmetric and multi-scale; maximum lift clamped below road and layer margins. | `audit_ground_drape` |
| Terrain-triangle adoption | `ground.js emitCell()`, quad helpers | Planning layer unchanged; triangle winding matched; shoreline gate on whole-face tests; no re-applied drape inside adopted layers. | `audit_ground_tile`, `audit_ground_drape` |
| Farm bunds and alignment | Bund/ring/emit helpers, farm gap, cluster gate | Neighbor size solved from shared edge aspect; bunds straddle footprint boundaries with derived gaps; outer vertical faces included; bunds gated on cluster size; roster derives from farm families. | `audit_ground_qc` |
| Seasonal farmland | `SEASON_I`, `seasonI()`, seasonal ground texture | Season enters only the brush cache key with unchanged material buckets; seasonal definitions skip the global tint; brush seeds season-independent with private randomness. | `audit_ground_tile` |
| Rockfield layout | `siteplan.js ROCKFIELD`, strike helpers, field planner | Strike derives from terrain gradient; adjacent rows stagger from the central row; shared phase and non-interpenetrating gaps. | `audit_siteplan` |
| Settlement trust ladder | `settlement()`, density, infill seeds, image classifier | Both building amplifiers feed from settlement; infill seeds finalize before block planning; locally normalized thresholds with derived fallback; image-only sources degrade through the fallback order. | `audit_siteplan` |
| Venue mix vs survey | `VENUES.mix`, landcover queries | Mix consumers restricted to classification and boundary placement; areas clipped to bounding boxes; unsurveyed venues marked unverified, never blanket-approved. | `audit_venue_biome` |
| Beacons | `beacons.js` kind parts, extents, anchors, site planner | Reuse solved tower sites without recomputation; zero shared randomness with hash-carried appearance seeds; feet measured from part extents; height graded by clearance. | `audit_beacons` |
| World text | `worldtext.js resolveName()`, `SignSheet`, aspect, cell packer | MUST NOT placard unnamed features or filler names; all text merges into one mesh and one atlas within budget; placard aspect derives from style; back-to-back quads; dropped signs logged. | `audit_world_text` |
| Vernacular corpus | `vernacular.js pickName()`, `pickRef()`, `signCopy()` | Zero-import; local script primary with latin alias secondary; daily sublines accept free-text fields only; global dedupe; fixed draw counts with dedicated seeds. | `audit_vernacular` |
| Part-library consumption | `partlib.js` libraries, `biomes.partGeo` | Layout math reads only fuse geometry, MUST NOT read load-dependent library geometry; offline node lists derive from library names. | `audit_siteplan` |
| Background assembly | `RUNTIME_BACKGROUND_CATALOG`, `generateBackgroundObject()`, part transforms | Master structure and slot rosters fixed; source groups map by local frames with target-slot joints; palettes sampled within subfamilies; deterministic with zero randomness; MUST NOT attach NPC, combat, or player units. | `audit_background_objects` |
| Building mass buckets | `BLD_LIB`, `bldGeo`, `bldProfile`, bucket builder, budget families | Pick counts shared across tall and low buckets; picking is a pure coordinate-ordered function decoupled from load state; per-bucket fallback; collision from profiles; storey counts derived per piece. | `audit_siteplan` |
| Profile sections | `BLD_LIB` profile cell, `bldProfile()`, `profGeo()`, `fitNode()`, sign helpers | Oriented boxes stacked per segment enveloping the mesh; sign spots qualified by flat-wall area share under one filter. | `audit_siteplan` |
| Wall panels | `wallpanel.js planeGroups()`, panel/grid/UV helpers | Single grouping definition shared by runtime and offline measure; panel counts rounded with plain-band fallback; windows aligned by UV only. | `audit_siteplan` |
| Planarization and sealing | Tri-budget planar spec, `wallpanel.planeGroups` | One spec shared between blade and ruler; grouping by normal angle plus offset with capped cumulative displacement; positions moved only; denoise before merging; sealing from the first downward hit in the base band. | `audit_siteplan` |
| Rock polyhedra and strata | `biomes.js rockFrustum()`, megaliths, rock materials | Prefer non-box polyhedra; chamfer boxes via taper or shear, not placement rotation; never single flat colors — layered cel bands with strata, fracture tint, and top lichen. | `audit_rock_ink` |

Assertion details live in layer-4 audit script headers.
