Phase 2 BotW-Style Terrain Shading & Layer Blending

Objective: Build custom shaders to blend background landscape textures without creating repeating tiling tiling artifacts.

Task 2.1: Slope-Based Triplanar Texture Splatting

Action: Write a custom fragment shader that uses slope attributes to dynamically blend terrain textures. Flat surfaces automatically get the Painterly Grass texture; steep vertical slopes automatically map to the Chiseled Rock cliff texture.

Texture Imperfection Technique: Inject a low-frequency procedural noise map (Perlin or Simplex) to smoothly shift the color tint across the landscape, breaking up texture repetition and mimicking watercolor wash variations.

Acceptance Criteria: Seamless transitions from grass hills to stone cliffs with zero visible grid-tiling repetition from far camera distances.

Task 2.2: Vertex Color Weathering & Ambient Occlusion Baking

Action: Utilize vertex color channels (`geometry.attributes.color`) to paint localized environmental variations. Use channel R for baked ambient occlusion (shadowing under rocks), and channel G for moss accumulation.

Acceptance Criteria: Static ruins show darker, hand-painted ambient occlusion values around ground contact joints, firmly grounding the assets into the world.

Phase 3 Painterly Cel-Shading & Foliage Materials

Objective: Implement custom GLSL lighting models to achieve the signature soft-gradient anime illumination on static props.

Task 3.1: Custom Multi-Step Toon Lighting Shader

Action: Replace standard Lambert/Phong illumination with a custom fragment shader chunk. Calculate the dot product of the normal and the light direction (`dot(N, L)`), then feed the result into a soft multi-step ramp function using `smoothstep` rather than harsh, jagged cuts.

Color Control: Ensure shadow regions are tinted with a rich, stylized cool-blue or deep-teal shade instead of plain black or grey, matching the environmental bounce lighting of BotW.

Acceptance Criteria: All static background meshes react to directional light changes with painterly, illustrative tone gradients.

Task 3.2: Stylized Static Foliage & Shell Shading

Action: Set up stylized grass clump instances and leafy tree canopy clusters. Shaders for tree canopies must merge vertex normals outward from the center of the mesh volume (Normal Sphericalization) to create unified, soft cloud-like cel-shaded bundles rather than messy individual leaf lighting.

Acceptance Criteria: Foliage looks like clumps of solid painted color with broad anime shadow bands across the canopy. No realistic noise.
