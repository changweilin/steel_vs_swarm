# ACG 機體立繪生圖指南 —— 無人機篇（Drones）

本文件專供專案 12 部**航空無人機（Drones）**的立繪（Character Standee Art）生成與提示詞（Prompt）撰寫使用。

---

## 一、 通用生圖原則與 Prompt 規範

1. **【最高防呆準則】純航空飛行載具，嚴禁任何人形特徵**：
   * 所有無人機均為**純飛行載具（多旋翼、固定翼戰機、飛翼、仿生飛禽/飛龍）**。
   * **絕對不可出現**：人型軀幹、人臉、座艙罩內之人類駕駛、機械手臂、手掌、直立雙腿、步行足。
   * 武器一律為**機身內嵌、旋轉砲塔、機翼硬點掛架或機腹吊艙**，不可畫成由機械手臂「手持握持」。
2. **純粹 ACG 遊戲立繪風格（Game Standee Art）**：
   * 採用《電馭叛客：邊緣行者》與《奧術》的高對比鮮明線條與厚塗動態光影（Bold anime ink linework, dynamic cel-shading）。
   * 點綴微光六角戰術全息浮空能量粒子（僅為氛圍光效，不得生成文字視窗或圖表）。
3. **【最高防呆】嚴禁將機體名、角色名、招式名稱寫入生圖 Prompt**：
   * 絕對不可出現任何機體、角色或技能專有名詞，避免 AI 產生駕駛員實體或畫出字牌、文字浮水印。
   * 請一律直球描述**飛行器氣動構型、旋翼／推進器結構、武器發射狀態、裝甲塗裝與色彩**。
4. **【最高防呆】嚴禁任何畫面文字與圖表標註**：
   * Prompt 必備負向約束：`STRICTLY NO TEXT, NO LABELS, NO ANNOTATIONS, NO LEADER LINES, NO INFOGRAPHIC DIAGRAMS, NO BASE PEDESTALS`。
5. **避色色幕背景（Chroma-Key Background）**：
   * 背景色必須選擇該無人機**本體、武器、塗裝、徽記、旗幟、戰鬥光效中完全未出現的鮮豔單色**（如 Chroma Green `#00FF00`、Chroma Magenta `#FF00FF` 或 Chroma Sky-Blue `#0088FF`），確保能 100% 無損自動去背。
