# 角色設定集 — 無人戰略:鋼鐵與蜂群

> **內部設計文件。**本作為**平行時空之虛構創作**,靈感取材自現實事件,所有角色皆為虛構,與真實人物無涉。
> 每名角色的「設計原型」欄位僅供美術/寫作內部參考,**不得出現在遊戲內任何文字**。
> 原型採**三分律**:每名角色 = Unlight 要素 ⅓ + 其他 ACG 要素 ⅓ + 原創要素 ⅓;只取面向、必經微調,禁止照抄任何單一角色(詳見第六節)。主線劇情見 [story.md](story.md)。
> 美術方向:承襲 Unlight 式**手繪水彩暗色調立繪**(粗獷筆觸、高對比打光、寫實比例),
> 世界觀質感由哥德蒸氣龐克轉譯為**柴電龐克 × 戰地寫實**(鏽蝕鋼板、迷彩帆布、纏線束的改裝電子件)。

## 一、世界觀:第三次世界大戰(平行時空)

### 時間線
- **2022** 東歐戰爭爆發,與我們的時空同步。
- **2023–2025** 消耗戰。廉價 FPV 無人機改寫戰場經濟學:一枚 500 美元的自殺式無人機可以換掉一輛 300 萬美元的坦克。
- **2026** 「黑海事件」——一次跨境齊射波及三個北約成員國,歐洲直接參戰。
- **2027** 東亞第二戰線開啟(台海),台、日、韓被捲入;同年,因無人機技術輸出鏈,以色列與伊朗互相宣戰。戰爭正式全球化。
- **2028** 史家開始稱之為**第三次世界大戰**。兩大軍事學說徹底分裂:
  - **蜂群主義(Swarm Doctrine)**:「便宜、量大、可拋棄。」操作員遠端遙控,機體無限補充——死的是機器,不是人。
  - **鋼鐵主義(Steel Doctrine)**:「護甲讓士兵活著回家。」重裝雙足步行平台,駕駛員在裝甲艙內,彈射逃生艙保命,但機體昂貴、補充有冷卻。
- **2029–2031** 戰線遍及全球 21 處著名地標與風景區(即遊戲預設場地)。不結盟國家的**傭兵市場**空前繁榮。
- **遊戲時間點:2031 年。**

### 蜂群陣營 —「自由蜂群同盟」(The Free Swarm Coalition)
以**烏克蘭**為核心,美、歐、澳、台、日、韓、以等國志願者與技術力匯流。
文化基調:車庫改裝、開源韌體、群眾募資買零件、貼滿貼紙的控制箱。
組織鬆散但韌性極強——每個中隊都像一支樂團,吵吵鬧鬧,上了頻道卻嚴絲合縫。

### 鋼鐵陣營 —「大陸鋼鐵協約」(The Continental Steel Pact)
以**俄羅斯**為核心,中、北韓、伊朗、古巴等國的工業體系與人力整編。
文化基調:國家兵工廠、閱兵式塗裝、政治部標語、以及標語底下一個個活生生的人。
組織森嚴而龐大——但鋼鐵的縫隙裡,同樣長著懷疑、鄉愁與詩。

### 中立傭兵 —「不結盟市場」(The Non-Aligned Market)
土耳其、印度、巴西、南非、瑞士、蒙古、肯亞……不選邊的人在兩大陣營之間穿行:
賣軍火、送信、找人、簽一發一結的狙擊合約。戰場上有一條不成文的默契:**不打信使。**

### 機體混編(2031 年的現況)

兩大主義從來是**戰術學說**,不是機體規格表。打到 2031 年,雙方都已經吃過「只有一種機體」的虧:
純蜂群擋不住正面推進,純鋼鐵抓不到天上的東西。於是兩邊各自吸收了對方的機種——
學說沒有變,編制變了。

| 陣營 | 無人機 | 機甲 | 變形機甲 |
|---|---|---|---|
| 自由蜂群同盟 | **7** | 3 | 2 |
| 大陸鋼鐵協約 | 3 | **7** | 2 |
| 不結盟市場 | 2 | 2 | **4** |

機體隨陣營走,而**駕駛員的國籍隨機體走**:一具機體的仿生/文化原型屬於哪個國家,
它就落在那個國家所屬的陣營裡,由那個國家的人駕駛。
例:袋鼠機甲(S-09)在澳洲、齊天大聖變形機甲(T-06)在中國、
Shahed 三角翼(T-09)在伊朗、龍與翼龍(T-08 / T-07)在東亞、
吸血鬼變形機甲(N-01 渡鴉)在塞爾維亞——「vampir」這個字的出生證明就在那裡、
獵鷹無人機(N-04 霧行者)在蒙古(阿爾泰馴鷹世家)、
恐龍系機甲(N-02 磐石 / N-06 嘉年華)沒有國族象徵,所以留在不結盟市場。

**始祖鳥 ↔ 迅猛龍變形機甲(S-03)在台灣**(2026-08-03 定案):
牠不是鳥、也不是恐龍,分類學家吵了一百五十年,牠自己活得好好的——
一個夾在兩種分類之間、靠著「還沒被歸類完」就先活下來的東西,
交給那個把懸賞令當 KPI 貼在牆上的新竹晶片工程師,再合適不過。
飛行型張開的兩片翼面是一整片相控陣,收翼落地摺成背脊上的長天線:
同一組振子,兩種指向——這正是她本來就在做的事。

**第三條規則:傭兵的國籍必須是真的不結盟。**「不結盟市場」的八席若坐進北約/歐盟成員國的人,
就與世界觀直接衝突(那些國家在本作裡明寫是同盟的技術與志願來源)。
2026-08-03 依此清了四席:克羅埃西亞 → 塞爾維亞、葡萄牙 → 瑞士、加拿大 → 蒙古、德國 → 印度。

## 五之二、稱號與機體命名規則(2026-08-04)

1. **稱號是人的,機體名是裝備的。**兩者 MUST NOT 相同 —— 唯一具名豁免是 N-01 渡鴉:
   他賣的就是那個剪影,人與機體在他的生意裡是同一件商品,同名是他的招牌而不是疏漏。
2. **業務名詞誰都不歸,連機體也不歸。**傭兵的五個舊稱號(帳房 / 清算 / 外包 / 保全 / 尾款)
   原本全是行業術語,人物讀起來像一張發票。第一輪只把它們從人身上挪到機體上,
   結果那張發票只是換了個欄位貼著:選角畫面上,五台機體仍舊叫帳房、清算日、外包、保全、尾款。
   **2026-08-04 第二輪**:那些詞降為**只在對白裡出現的業務類別或市場舊稱**,
   機體改用形象化的名字:續命 / 鎖喉 / 傾盆 / 落閘 / 空號。
   —— 判準很簡單:機體名唸出來要像一個**動作或一個瞬間**,不像一個科目。
3. **每一個名字都要有由來**,而且由來寫在 `lore.js` 的 `bond` 裡(誰取的、為什麼換掉舊的)——
   名字是戰場上長出來的,不是自己宣告的。機體名同樣適用:改名的那一刻由駕駛員自己寫,
   而舊名 MUST 留在文本裡當對照(「原本叫 X,她自己把名牌蓋掉了」),否則讀者不會知道換了什麼。
4. 兩個「概念對但太平」的稱號同步改掉,概念不動、戲劇性補上:
   **S-07 鐵數學 → 鐵證**(數學是拿來吵的,證據不是)、

## 六、原型三分律(內部核對用)

每名角色的設計要素固定為 **Unlight ⅓ + 其他 ACG ⅓ + 原創 ⅓**,規則:

1. **只取面向,不搬本體**:每個原型只借「氣質/處境/技藝」其中一個面向,姓名、外貌、人際關係、劇情走向一律不搬;借來的面向必須經過至少一次轉譯(職業、時代、性別、動機任一項改寫)。
2. **允許複用、禁止重複**:同一原型可在多名角色間複用,但必須取**不同面向**,並在原型欄標註「與 X-XX 取向不同」(例:瑪格麗特之於 S-08 是「聖武並存」、之於 T-10 是「胸口藏著的祈禱」)。
