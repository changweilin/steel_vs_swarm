# 全體與分類機體建模與運動指引 (General & Categorized Mech Authoring Guidelines)

> 本文件統整 3D 機體建模、骨骼拓撲、關節裝甲、武器裝備與動態呈現之**通用與分類原則**。
> 本規範定義全體架構、體態分類與武器裝備之設計邊界與物理不變量，並標明所屬機體編號（不包含個別數值調平或歷史修訂紀錄）。

---

## 一、全機體共通注意事項 (Universal Mech Invariants)

| 項目 | 規範與物理邊界 | 失敗模式與約束 (Failure Modes & Constraints) |
| :--- | :--- | :--- |
| **剛性關節與分離裝甲** | 關節一律為剛性分離裝甲，禁止跨肘／跨膝直接拉伸蒙皮。機械旋轉依靠球鉸鏈、滑軌或套筒軸承呈現。 | 避免金屬裝甲出現如生體組織般的軟質拉伸與形變；轉向極限角度不可發生幾何面穿模破面。 |
| **呈現層邊界 (Single Seam)** | 護盾網格、雷達波膜、光學迷彩與所有粒子特效皆為純呈現層（Client-side Presentation）。 | 嚴禁視覺特效更動伺服器端數值（HP、護盾值、傷害量、碰撞半徑、裝填時序等權威判定）。 |
| **尺寸估算與不可見面推斷** | 視覺標註尺寸為立體比例推算；非可見面（背腹艙門、鉸鏈路徑、散熱柵、管線連接點）需依功能性補足機械合理結構。 | 禁止製作空殼幾何；關節背隙、腹艙收納容積與運動支點必須具備足夠物理深度與活動間隙。 |
| **護盾發射與動作優先級 (Mounting & Action Priority)** | **護盾發射器安裝優先順序**：**盾牌 ＞ 冷兵器 ＞ 其他**。<br>1. **第 1 優先（盾牌）**：裝備盾牌者以盾牌為發射陣列；<br>2. **第 2 優先（冷兵器）**：無盾但裝備冷兵器者，整合於冷兵器本體（槍尖／斧身／棍頂／弓臂）；<br>3. **第 3 優先（其他）**：無盾無冷兵器者，單手持槍者安裝於非慣用手小臂外側平貼（1 個發生器），雙持武器者安裝於兩武器上，機載/無手持者安裝於機身對稱外緣。<br>**防守招式動作施展亦嚴格依此優先順序設計**：<br>持盾頂推衝撞 ＞ 冷兵器格擋架勢 ＞ 小臂身軀戒備。 | 護盾發生器不得阻礙手臂旋轉、握把抽拉或槍機動作；展開半徑需包覆核心軀幹而不破壞射擊視角；防守動作不可與行走/奔跑骨骼產生穿模衝突。 |
| **功能性軀幹分段 (Axial Regions)** | 脊椎動物與人形仿生必須具備功能性頭、頸、肩、胸腔、腰身與骨盆分段；昆蟲需具頭、胸、腹；頭足類具外套膜與放射腕足。 | 嚴禁單一長方體或無關節的一體化僵硬軀幹；軀幹幾何必須支援側傾、軸向扭轉與前後拱背，不可僅依賴骨骼命名而幾何不形變。 |
| **步態動力學與相移 (Locomotion Kinematics)** | 前肢（肱骨／尺骨／掌骨）與後肢（股骨／脛骨／蹠骨）運動曲線需具備明確的承重（Loading）、蹬地（Push-off）與復位（Recovery）三階段。 | 避免使用通用簡諧正弦波驅動四肢；受載手腕或腳踝可短暫支撐緩衝，但整條肢體嚴禁呈現筆直棍狀擺動。足底需有穩定接地接觸點。 |
| **持武瞄準與射擊姿態 (Weapon Aiming & Stance)** | 手持熱兵器時，依據實際持槍手選用斜向戒備姿態（Oblique Stance）；骨盆、腰椎與胸椎共同分擔轉向，肩肘向內微收，頸部代償補償前方視線。握柄虎口必須貼緊上緣頸部／海狸尾，食指自然就位扣扳機。 | 嚴禁握在握柄尾端或底部（不合人體工學且無法扣引扳機）。機載武器嚴禁觸發手持持槍姿態。槍管軸線與手臂延伸方向一致，射擊指向恆朝瞄準方向。 |
| **軸向波動與尾部傳遞 (Spinal & Tail Waves)** | 連續脊椎與尾部關節在移動與待機時，需由基底向末梢傳遞延遲的橫向與垂直波動，維持物種專屬之剛性與自然蜷曲。 | 嚴禁將整條尾巴綁定為單一旋轉關節或整體平移；鳥類尾扇保持短控制舵面姿態，水生尾鰭維持背腹或側向規則推進波。 |

## 二、體態分類注意事項 (Categorized Mech Morphologies)

### 2.1 人形機體 (Humanoids)
- **涵蓋機體編號**：`t01`、`t02`、`t10`、`t12`、`t11`（步兵地面型）、`m01`（吸血鬼地面型）

| 檢驗項目 | 規範與解剖要求 | 結構與動態約束 |
| :--- | :--- | :--- |
| **四肢解剖鏈** | 上肢肱骨、尺骨、掌骨與下肢股骨、脛骨、蹠骨的連動與關節限位需嚴格符合人體解剖動力學。 | 關節轉動需具備機械限位，膝關節禁止出現非特化之反向過伸（Hyperextension）。 |
| **手部解剖與肩腕活動度** | 手部掌指骨、腕關節與雙肩需具備完整多軸旋轉自由度，支援側向抬臂、內收與雙手協同架勢；手部持握各類武器之細節與人體工學要求，一律歸入「三、武裝裝備分類注意事項」。 | 腕關節不可呈現鎖死剛棍；雙肩需與上胸鎖骨連動，避免手臂抬起或端槍時胸廓無相應形變補償。 |
| **胸腰分離與骨盆結構** | 胸甲與腰部外骨骼必須分離設計，明確勾勒腰身收窄過渡與骨盆承重結構。 | 避免腹部為單一無接縫裝甲塊；骨盆需提供大腿關節球窩足夠的轉動軸心間隙。 |

### 2.2 仿生獸型 (Bionic Beasts & Multi-legged Mechs)
- **涵蓋機體編號**：
  - **雙足直立／深屈獸型**：`t06`（靈猴地面型，前傾靈長類步態）、`m05`（深屈狼人地面型）、`m02`（水平暴龍）、`t03`（拱背巨猿）、`s09`（深蹲袋鼠）、`s10`（深蹲迅猛龍地面型）
  - **四足奔跑／重裝獸型**：`s06`（半人馬戰馬軀）、`t04`（低伏獵犬）、`m06`（劍龍柱狀腿）、`s03`（巨象地面型）、`m08`（消音黑豹地面型）
  - *(註：涉禽鶴體 `t05` 見本節四肢反曲；頭足綱 `s07` 移入 2.6 節)*

| 檢驗項目 | 規範與解剖要求 | 結構與動態約束 |
| :--- | :--- | :--- |
| **雙足直立獸 vs 四足獸區分** | **嚴禁雙足獸型與四足獸型混淆**：<br>1. **雙足獸型（靈猴/狼人/暴龍/巨猿/袋鼠/迅猛龍）**：脊椎拱背或水平前傾，重心壓低；下肢為反曲高位跗骨深蹲（Z 形關節）或靈長類低姿躍進；**嚴禁畫成四足貼地奔跑，亦嚴禁做成人類直立膝關節與垂直站姿**。<br>2. **四足獸型（半人馬/獵犬/劍龍/巨象/黑豹）**：前後肢解剖鏈完全分工（前肢肩-肱-尺-腕掌 vs 後肢骨盆-股-脛-蹠），具備標準四足對角步態（Trot/Gallop）或象柱腿穩固承重；**嚴禁站立行走，嚴禁長出人手人腳**。 | 雙足深蹲獸型轉彎與跳躍時維持反曲彈性；四足獸型四蹄/四爪必須均勻著地承受機體質量，行走時不可同側手腳同步擺動（避免順拐畸形步態）。 |
| **四肢解剖鏈與步態特化** | 依物種特化足部構型：蹠行（Plantigrade）、趾行（Digitigrade，深屈 Z 形跗關節）、蹄行（Unguligrade，象柱腿／戰馬蹄）需嚴格區分。 | 反曲足爪與深蹲關節需維持低重心張力；長臂巨猿（t03）前臂過膝觸地，保持三點或四點爆發衝刺態。 |
| **尾部動態平衡與脊椎前傾** | 粗大平衡長尾（暴龍 m02、袋鼠 s09、迅猛龍 s10）或剛性尾槌需與前半身質量形成槓桿平衡，於奔跑、跳躍與變向時提供動態補償。 | 尾巴需自然擺動以抵消前進慣性，不可死硬直挺；身軀胸腔體積需充足，腰腹適度收束以保留後腿擺動行程。 |

### 2.3 飛行生物 (Aerial Biological Mechs)
- **涵蓋機體編號**：`t07`（翼龍）、`m04`（獵鷹）、`s10`（始祖鳥飛行型）、`m05`（滑翔飛鼠飛行型）、`m08`（夜梟飛行型）
- *(註：東亞神龍 `t08`、飛鯨 `s03`、犀角金龜 `m07` 移入 2.6 節特化規範)*

| 檢驗項目 | 規範與解剖要求 | 結構與動態約束 |
| :--- | :--- | :--- |
| **翼前肢同源轉換與收折** | 鳥類、翼龍與翼膜獸型的翅膀為脊椎前肢同源演化（肱骨／尺橈骨／掌指骨）。折翼時需呈現自然的 Z 形收折（腕部後屈、指端朝後收束貼身）。拍翼時肱骨下壓、尺骨前臂延遲撲展、羽片或翼膜具備氣動扭轉。 | 嚴禁折翼時如人手臂般直接垂放兩側；拍打時禁止如剛性單片鋼板整體上下平移。翼面羽片或翼膜前緣不得超前骨骼肢體。 |
| **肢爪飛行態與狩獵張力** | 飛行姿態下雙爪允許兩種張力表現：<br>1. **巡航態**：向後收攏貼腹或扣入腹部凹槽；<br>2. **狩獵／俯衝態**：後爪可向前或斜前伸展微屈，肌肉／液壓張力緊繃呈抓捕掠食姿態。 | **唯一嚴格禁止：無張力的呆板垂直下垂**，亦禁止如陸行站立般鬆垮拖地。 |
| **後肢骨盆連動與反曲緩衝** | 飛行生物後肢在空中處於懸浮或抗風張力，骨盆需提供股骨足夠的前後擺幅；切換至地面或深蹲獵殺態（如 s10、m08）時需具備獸型反曲關節（股骨-脛骨-跗骨-趾爪）的承重緩衝。 | 嚴禁將飛行生物後肢設計為直立人腿膝關節；飛行與地面型態轉換時，關節折疊路徑必須清晰且無穿模。 |
| **尾羽控制面與視線補償** | 鳥類與涉禽型必須配置收放自如的尾羽扇面；頭頸部需具備前向視線主動穩定補償。 | 尾部需具備俯仰與偏航控制面幾何；軀幹起伏撲翼時頭頸需主動抵消晃動維持視線水平穩定。 |

### 2.4 飛行載具 (Aerial Crafts & Drones)
- **涵蓋機體編號**：`s01`（四旋翼蜂型）、`s02`（六旋翼轟炸型）、`s04`（前掠翼突擊型）、`s05`（FPV四旋翼穿越型）、`s08`（共軸雙旋翼球型）、`s11`（大展弦比滑翔型）、`s12`（鴨式三角翼型）、`t09`（無尾大三角飛翼型）、`m03`（雙尾桁搜救型）、`t06`（筋斗雲飛翼型）、`t11`（傾轉旋翼巡邏機型）、`m01`（超音速三角滑翔型）

| 檢驗項目 | 規範與解剖要求 | 結構與動態約束 |
| :--- | :--- | :--- |
| **四肢與人型特徵嚴格排除** | 純旋翼機、多軸無人機、固定翼突擊機與飛翼巡邏機一律嚴禁出現任何多餘的機械人手或直立雙腿（除指定之收納機構或起落架外）。 | 保持純飛行載具之氣動與懸浮特徵；嚴禁在純飛行器上繪製人形駕駛外骨骼或人臉面甲。 |
| **武器外掛與動態淨空** | 機頭軸向武器、機翼導軌掛架與機腹旋轉砲塔需一律維持正向發射軸線，並與推進旋翼／排氣噴口保持安全物理間隔。 | 砲管與飛彈發射軌跡不得穿透旋翼葉片旋轉平面或進氣道涵道結構。 |
| **裝甲厚度與結構支撐** | 機身底盤、加強筋、涵道桶壁與感測艙需呈現出真實的複合裝甲板厚度與鉸接鉚釘細節。 | 避免空殼單層薄板或單純等比縮放；重載機種應透過結構梁柱、散熱柵與維修艙蓋厚度展現量感。 |

### 2.5 變形機體 (Morphers & Dual-Form Units)
- **涵蓋機體編號**：`s03`（飛鯨 70% ↔ 巨象 30%）、`s10`（迅猛龍 70% ↔ 始祖鳥 30%）、`t06`（齊天靈猴 70% ↔ 筋斗雲飛翼 30%）、`t11`（阿特拉斯步兵 70% ↔ 傾轉旋翼機 30%）、`m01`（吸血鬼 70% ↔ 三角滑翔翼 30%）、`m05`（狼人 70% ↔ 滑翔飛鼠 30%）、`m07`（犀角金龜 70% ↔ 重裝陣地 30%）、`m08`（消音黑豹 70% ↔ 展翅夜梟 30%）

| 檢驗項目 | 規範與解剖要求 | 結構與動態約束 |
| :--- | :--- | :--- |
| **構件守恆與同名共用** | 兩種端點型態（70% 主型態與 30% 次型態）必須共用同一套剛性零件與拓撲關節鏈。 | 嚴禁在型態切換時憑空增減結構構件；變形對應零件（如主翼↔披風、腹艙↔象身、尾翼↔背板）尺寸與體積必須守恆。 |
| **武器錨點與掛載連續性** | 重型與輕型武器在型態轉換後，其物理安裝基座與空間指向必須維持幾何連續性。 | 武器不得在型態切換過程中憑空隱形或轉移至不合邏輯的懸空位置；手持武器在收納態需有專屬鎖定卡槽。 |
| **雙向幾何行程與無穿模驗證** | 鉸鏈旋轉路徑、連桿伸縮行程與滑軌滑動空間必須在 3D 空間具備物理可行性。 | 雙向過渡（Form A $\leftrightarrow$ Form B）端點必須完全重合，且運動過程中零組件之間不得發生硬性幾何穿模。 |

### 2.6 特殊與非標準體態 (Special & Non-Tetrapod Morphologies: 龍、鯨、克蘇魯頭足綱、昆蟲)
- **涵蓋機體編號**：`t08`（東亞機械神龍）、`s03`（飛鯨飛行型）、`s07`（克蘇魯頭足綱）、`m07`（犀角金龜兩態）、`s01`（蜂型頭胸腹分節軀幹）

| 體態類型 | 核心解剖規範與運動特徵 | 關鍵禁忌與幾何邊界 |
| :--- | :--- | :--- |
| **東亞長身神龍 (Dragon: t08)** | 蜿蜒修長蛇形機械身軀（26 個連續脊椎關節），由頸部引導向身尾傳遞連續橫向行波。空中飛行與盤旋時四爪緊扣腹側，龍角雙鬚與發光利齒齊全。喉部配置音波巨砲，角基整合諧振步槍。 | **龍首必須維持前向穩定補償**（飛行、轉彎與開火時頭部禁止隨身體晃動或脫離頸椎）；**嚴禁畫成雙足站立之西方蜥蜴龍人**；無旋翼，嚴禁背部长出多餘風扇螺旋槳。 |
| **飛鯨／巨海獸 (Cetacean: s03 飛行型)** | 巨型流線機械鯨體，背部整合指揮塔艦橋，胸鰭展開相控陣雷達。空中推進由身體波狀起伏與**上下方向撲動之水平尾鰭／尾葉（Dorsoventral Fluke Stroke）**驅動，胸鰭維持俯仰與穩定微調。 | **嚴禁模仿魚類／鯊魚之左右橫向甩尾**（鯨類為背腹垂直撲動）；飛行型態下**四足必須完全收入腹部密封滑槽內，嚴禁任何外露象腿懸垂**；獨角螺旋光矛與象鼻為同源共用件。 |
| **克蘇魯頭足綱 (Cephalopod: s07)** | 卵圓形外套膜、背部感測圓盤與兩側機械複眼；擁有恰好 8 條獨立多節柔性觸手（4 條下部接地爬行支撐觸手、2 條兩側高位持武觸手、2 條前後自由感知觸手）。地面運動為**章魚式放射狀爬行（Octopus Radial Crawl）**。 | **嚴禁人類面甲、直立雙腿或人身背長觸手**；嚴禁生搬硬套四足哺乳類走法步態；兩側持武觸手需向上抬高以確保左右複眼視野淨空；各觸手運動需維持護套連續性，禁止互相穿模。 |
| **昆蟲與節肢 (Insects: m07, s01)** | 嚴格維持**頭、胸、腹三節外骨骼架構**，具備金屬口器與複眼感測陣列。六隻步足皆為關節節肢配多節跗節（Tarsi）。m07 具備雙排厚重五角金屬鞘翅（Elytra）可向上呈 V 字掀開，露出下方高頻微幅撲動之透明機械膜翅；平時鞘翅緊密閉鎖構成不動鐵壁。 | **昆蟲沒有哺乳類脖子**！**六隻腳嚴禁畫成獸爪肉墊或人形雙腿**；翅膀為胸背板外骨骼特化鉸接，**絕對不可將六隻步足誤當成翅膀**；飛行膜翅僅負責撲打懸停，不可與鞘翅防盾混為單一構件。 |

## 三、武裝裝備分類注意事項 (Weapon & Equipment Categories)

### 3.1 手握槍枝（熱兵器） (Handheld Firearms / Thermal & Kinetic Ranged Weapons)
- **涵蓋機體編號**：`t01`（左手重機槍）、`t02`（衝鋒槍）、`t03`（左手彈鼓霰彈槍）、`t06`（突擊步槍）、`t10`（右手速射砲）、`t12`（右手脈衝雷射長槍）、`m01`（右手加特林機槍）、`s07`（觸手抓持空爆砲）、`s09`（右手防空霰彈槍）、`s10`（前爪握持脈衝雷射）

| 檢驗項目 | 規範與操作要求 | 結構與動態約束 |
| :--- | :--- | :--- |
| **握把人體工學與扳機位置** | 手掌握持時，虎口必須緊密貼合握柄上緣頸部（海狸尾下方），食指自然伸入扳機護弓並搭於扳機上。 | **嚴禁手掌捏在握柄尾端或底部懸空**：此為嚴重幾何拓撲錯誤，完全脫離人體工學，且物理上失去施力點無法扣引扳機。 |
| **槍管軸線與射擊指向** | 槍管軸線需與持槍手臂（小臂延伸軸線）保持完全平行同向；手腕需保留足夠多軸靈活度以校正瞄準點。 | 手持射擊時槍口恆朝前向目標；開火時不可出現手腕關節脫臼、槍身橫向側歪或後座力導致手臂反向扭曲。 |
| **斜向持槍戒備姿態** | 手持長槍、卡賓槍或步槍瞄準時，軀幹微轉呈現斜向戒備姿態（Oblique Stance），由骨盆、腰椎與胸腔分擔轉向，頸部代償補償前方視線。 | 不得以完全正面僵硬朝前的軀幹強行扭轉手臂端槍；雙手端槍時輔助手與前護木需有穩定接合點。 |
| **供彈機構與活動淨空** | 彈匣、彈鼓、彈鏈箱或散熱導管等外掛組件，需與手臂內側護甲保持合理物理間隙。 | 換彈、持槍奔跑與射擊後座力行程中，供彈組件與機體前臂、胸甲之間嚴禁發生硬性面穿模。 |
| **機載火器排他邊界** | 整合於頭部、口部、肩部、背部導軌或機翼下之固定/旋轉火砲，純屬機載武器（見 3.4 節）。 | 機載武器嚴禁繪製手持握柄，亦不可觸發人形手持射擊姿態。 |

### 3.2 持有冷兵器 (Equipped Melee / Cold Weapons & Polearms / Bows)
- **涵蓋機體編號**：`s06`（磁軌反曲弓）、`t01`（深冷急凍戰斧）、`t02`（電磁穿甲長矛）、`t05`（翼藏光子長矛）、`t06`（如意金箍杖）、`s04`（機鼻工兵鏟破甲衝角）、`s10`（電磁穿顱長矛／折疊羽刃）

| 檢驗項目 | 規範與操作要求 | 結構與動態約束 |
| :--- | :--- | :--- |
| **長柄武器力矩與握距** | 長矛、長槍、長棍、戰斧等長柄武器需具備足夠長度（禁止縮水為短劍短匕比例）。雙手持握時必須有明確的前後手握距以構成施力槓桿。 | 單手持握時接觸點需位於整體重心平衡點後方；握持位置不得浮空或穿透手掌模型。 |
| **刃面朝向與揮擊軌跡** | 斧刃、矛尖、刀鋒朝向必須與預定之刺擊、劈砍運動平面完全一致。 | 揮舞與突刺過程中嚴禁出現反刃、刃面扭轉或關節逆向彎折的非物理表現。 |
| **弓箭拓撲與弦矢連動** | 持弓手穩固抓持弓身把手中心；拉弦手需精準咬合箭尾（Nock）與弓弦節點，完整經歷引弦（Draw）、釋放（Release）與復位（Recovery）週期。 | 弓身、弓弦與箭矢需分別維持手部與骨骼約束；放箭瞬間箭矢幾何消隱轉由投射物彈道接手，嚴禁殘留雙重箭矢。 |
| **冷兵器護盾整合與防守動作** | **次級優先（無盾時）**：無盾牌但持有冷兵器者，以冷兵器本體（長矛尖端、斧身、長棍頂端、弓臂）作為護盾發射陣列。防守招式動作優先施展武器格擋、轉棍力場或立架架式。 | 避免在冷兵器外額外掛載突兀無用的副盾或浮空零件，保持冷熱交織之簡潔結構；格擋動作需正對攻擊來向。 |

### 3.3 持有盾牌 (Equipped Shields & Deployable Defenses)
- **涵蓋機體編號**：`t01`（霜狼重盾）、`t03`（合金推土防盾）、`t11`（雙手旋翼圓盾）、`m01`（滑翔翼披風防盾）、`s02`（底盤強化重盾）、`s07`（非歐拓撲偏折盾）、`s10`（天塹巨翼盾）、`m07`（鞘翅重甲盾）

| 檢驗項目 | 規範與操作要求 | 結構與動態約束 |
| :--- | :--- | :--- |
| **護盾發射與固定第一優先級** | **第一優先（最高優先）**：裝備實體盾牌（重盾／圓盾／推土盾／鞘翅甲盾）者，護盾發射器一律優先整合於盾面或盾框，以盾牌為防禦發射主陣列。盾牌本體由前臂外骨骼扣具、滑軌固定架或抓握把手穩固鎖定於手臂外側。 | 凡具備盾牌者，禁止將護盾發生器降級安裝至背部或武器末梢。大型重盾需配置粗壯雙手握把或液壓支撐臂。 |
| **持盾防守與衝撞動作第一優先級** | **防守招式動作第一優先**：機體施展防守招式時，優先以盾牌為動作主體，呈現持盾頂推、格擋閉鎖或持盾衝撞；身軀壓低微蹲、重心前傾，持盾手臂肘部向內閉鎖，對側肩膀後撤形成穩固三角形防衛面。 | 衝撞時盾面正對前進矢量，盾身需完全遮蓋核心乘員艙或動力核心；不得在衝撞時盾牌傾斜外露要害。 |
| **活動行程與視線淨空** | 盾牌外廓尺寸在手臂屈伸、武器換彈及待機擺動時，不得與手肘關節、肩甲或腰部副武器發生幾何穿模。 | 盾面不得遮蔽頭部主光學感測器視線，盾身邊緣需保留觀測縫或透明偏折窗。 |
| **呈現層邊界守恆** | 實體盾身幾何、展開之能量力場及偏折光幕均屬於純呈現層（Client-side Presentation）。 | 不得更動伺服器端碰撞半徑、格擋減傷倍率或抗擊退數值，保持單一真相縫。 |

### 3.4 機載與固定火器（無手持握柄／體表發射陣列） (Mounted & Airframe-Integrated Weapons)
- **涵蓋機體編號**：`s01`、`s02`、`s03`、`s04`、`s05`、`s08`、`s11`、`s12`、`t04`、`t07`、`t08`、`t09`、`t10`（肩部垂直發射箱）、`t11`（肩上托盤火器）、`t12`（眉心電磁貫通砲）、`m02`、`m03`、`m04`、`m05`（背部電磁機砲）、`m06`、`m07`（背甲防空砲）、`m08`

| 檢驗項目 | 規範與操作要求 | 結構與動態約束 |
| :--- | :--- | :--- |
| **剛性導軌與發射軸線** | 機載機槍、航砲、飛彈莢艙、垂直發射箱或雷射鏡頭直接固定於機身、背脊導軌、肩部台架或腹艙滑軌，射擊軸線由載具轉向或雲台仰俯控制。 | 嚴禁繪製人手抓握之握柄；發射軸線與砲口方向需正對前向射界，後座力由機體主結構液壓阻尼吸收。 |
| **隱藏式重火器快門行程** | 藏於口部（m02）、喉部（t08）、眉心（t12）或翼下艙門內之重武器，平時具備密閉鉸鏈快門或折疊護蓋，僅在重射擊蓄力/發射時開啟。 | 快門開啟與旋轉行程需具備清晰機械鉸鏈軸，關閉時需與周圍裝甲外廓平滑密封，禁止憑空出現或幾何穿面。 |
| **無盾無冷兵器護盾發射原則** | 本類純機載機體若無實體盾牌亦無冷兵器，護盾發射器依「**第 3 優先（其他）**」處理：單手武器者安裝於非慣用臂小臂外側平貼，純載具/獸型安裝於機體或胸側對稱發射陣列。防守動作以機體核心閉鎖、提肘抗震或低伏蓄力呈現。 | 護盾力場半徑需均勻包覆機身，不得偏向單側或干擾飛行舵面、旋翼流場。 |
