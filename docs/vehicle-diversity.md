# 陸上車輛分類與外觀生成

`public/js/vehicleCatalog.js` 定義 93 種原型與 23 種編組；用途、行走結構、動力與場域以相容表交集選擇。無結果時回空集合，指定不合理組合時明確報錯。這是遊戲美術設計，公稱尺寸不作工程規格或戰鬥數值使用。

| 維度 | 設計 |
| --- | --- |
| 用途 | 農業、畜牧、林業、工業、貨運、私人、載人、觀光、科學、軍事、競技、救援、市政 |
| 結構 | 兩輪、三輪、四輪、大型多軸、越野、履帶、鐵道 |
| 動力 | 人力、獸力、蒸氣、汽油、柴油、電池、架空供電、油電、氫燃料電池 |
| 尺寸 | 每型抽取車長範圍，寬高依該型比例派生，防止獨立抽樣造成扁車或細長車 |
| 車齡 | 自行車 0–25 年、競賽自行車 0–8 年、轎車 0–35 年、農機 0–45 年、軌道客車 0–50 年；保存型蒸汽機車 40–130 年。各型完整範圍見型錄 |
| 保養／磨損 | 保養 30–100%；磨損依相對車齡與保養推導，上限 85%。老車可以保養良好，外觀不改變性能 |
| 顏色 | 民用 6 色、作業 4 色、軍用 3 色、救援 2 色、競技 3 色，磨損最多使漆色明度降低 21.25% |
| 灰塵 | 街道車 0–25%；其他場域 0–65%，表現為車身下緣積塵 |
| 文字 | 用途字樣與 001–999 編號；民用塗鴉機率 12%，具有軍事／政府／醫療／救援／競技用途的車型為 0。字面固定在實際車體表面，兩側均正向閱讀 |
| 零件 | 工作件必裝；車架行李架、籃子、側袋、馬車篷頂各 60% 機率。排氣、電池與集電弓由動力決定 |

原型涵蓋自行車、貨運三輪車、機車、競賽自行車、手推車、馬車、轎車、計程車、拉力車、科考車、曳引機、收割機、集材車、牲畜貨車、堆高機、挖掘機、貨車、巴士、觀光巴士、救護車、清掃車、装甲運兵車、戰車、電力軌道車、柴油軌道車、蒸汽機車。

人力不搭重型裝甲，獸力只搭有牽引桿的停放馬車（未繫掛動物）。鐵道車只列入鐵道場域，蒸汽車只列入保存鐵道場域；電力車不裝排氣管，柴油軌道车不裝集電弓。動力是靜態外觀分類，沒有新增駕駛、武器或載客模擬。

共同背景入口支援 `vehicle/<原型>`，使用 `generateSharedBackgroundObject` 生成零件。`makeProceduralVehicle` 走遊戲既有零件編譯器與 `SignSheet` 文字圖集，車頭 +X、輪胎接地；宿主提供 fit 時按實際包絡縮放。不得從美術外廓反推碰撞或改動共享亂數。

全部 93 種車型由新的程序幾何建立，不使用核准照片車模，也不借用舊 `makeVehicle` 的車身、車艙或輪組。道路車與列車、停車場、殘骸、邊界貨車／車列均接入新模型。舊照片車模已從共同場景車輛名冊移除，來源檔只留作歷史資產。

`vehicleParts.js` 適配舊描述子宿主，外觀使用新型錄。停車場的權威碰撞柱保留原契約，以 `collisionOnly` 標記並由渲染器跳過；這些列不作可見模型。貨櫃仍是獨立物流構件。其他專用車型可由共同型錄與試車場生成，尚未新增農場／工地／基地的自動散布點。

開啟試車場：執行 `node test/architecturePreview.mjs`，瀏覽 `http://127.0.0.1:8644/vehicles`。可篩選三個分類、選原型、更換種子與拖曳觀察。設定 `THREE_MODULE` 與 `THREE_PASS` 可使用本機同版本 Three.js 及 `postprocessing/Pass.js`；預覽沿用遊戲後製，以正確解碼材質顏色。

驗證：設定 `THREE_MODULE` 後執行 `node test/vehicleDiversity.mjs`，以及既有 `tools/audit_vehicle_spec.mjs`、`tools/audit_background_objects.mjs`、`tools/audit_client_syntax.mjs`、`tools/audit_gpu_lifecycle.mjs`。

## 完整編組

vehicleConsists.js 提供 11 種列車與 12 種聯結車配方。列車採柴油或電力機車加 2–6 節貨車，聯結車採道路牽引車加 1 節半拖車。後方車廂只能使用無動力牽引；配方限制牽引車及載荷，拒絕不相容組合與超限節數。

列車共用遊戲軌距 1.435 m 與車鉤高度 0.85 m；半拖車第五輪與主銷高度固定 1.2 m。各車依連接點定位，每節外觀使用獨立、可重現的種子。電力機車需要架空供電場景，預覽目前不生成供電設施。

共同入口支援 consist/<配方>，例如 makeProceduralVehicle('consist/timberTrain', 42, {leaderKey:'dieselLocomotive', wagonCount:4, wagonKey:'railLogs'})。

試車場增加單車／車廂、整列貨運列車、完整聯結車模式，可選牽引車、車廂及節數。本次運行網址為 http://127.0.0.1:8645/vehicles；預設啟動命令仍使用 8644。完整編組已進共同型錄，尚未新增長列車自動散布點；原有短車位仍按宿主碰撞盒容納單車。

造型參考：[Greenbrier 貨車分類](https://www.gbrx.com/find-your-railcar/)與 [Chart 低溫槽車](https://www.chartindustries.com/Products/Cryogenic-Transport-Trailers)。簡化幾何與參數為遊戲設計，不代表廠商工程規格。

## 外形與接合修正

攪拌筒採前低後高的三段旋轉體，兩端收束，後方保留卸料口、料斗、溜槽與支架；垃圾車改為壓縮艙、削角頂肩、後裝填斗、側頰與尾門油壓桿。雲梯採雙層桁架與內套梯，吊臂加厚並連接轉台、樞軸座與運輸支架。駕駛艙前擋置於正面外表，警示燈跟隨實際屋頂。

補齊後視鏡座、燈具背板、駕駛艙座、原木枕樑、轉向架承座、第五輪底座、集電弓座、載運汽車輪組及小型車配件支架。造型參照 [Liebherr 攪拌車](https://www.liebherr.com/en-int/p/97529-5379125)與 [Rosenbauer 雲梯車](https://www.rosenbauer.com/en/products/vehicles/aerials/aerial-ladders)，仍屬簡化遊戲幾何。

執行 node test/vehicleAttachments.mjs 檢查 948 組車型／動力／種子：前擋露出、攪拌筒方向及零件包絡連通。包絡間隙容許值為 1.5 cm；包絡相交不能證明曲面確實接觸，因此此測試只作懸空回歸篩檢，不能替代畫面檢查。本輪瀏覽器控制連線中斷，尚未完成畫面複驗。

## 車牌與專用設備

道路牌照改用端面牌架與 plates 定位資料，文字朝向正前／正後並貼在牌面外側；機車只掛尾牌，半拖車尾牌偏側，垃圾車使用後裝填斗下緣牌架。完整聯結車只顯示牽引車前牌及末端拖車後牌。車隊側面字樣與車牌分開，鐵道保持車隊編號而不加道路牌照。SV 編號為虛構遊戲格式。

泵送臂、高空斗臂、伸縮吊臂分別使用折疊鉸節、折返臂與套筒；傾卸車改為有尾門及油壓桿的貨斗。推土機與鋪路機改用工程機械上身，鋪路機包含輸送帶、螺旋攤料器、操作台與遮頂。槽罐的燃油出油歧管、飲水龍頭、衛生閥罩、吸污後門，及棚車滑門、廢料密閉蓋、箱式貨廂門鎖皆為可見專用幾何。

消防、排水、發電與工具櫃分別配置壓力表、離心泵殼、電源插座及抽屜把手。另補指揮車天線碟、囚車門閂、醫療尾門、露營車側門、圖書車書架及書脊。底盤與基本幾何工具仍共用；功能設備由各用途分支生成。vehicleAttachments.mjs 包含車牌端面與貼合檢查，以及主要專用幾何防退化斷言。
