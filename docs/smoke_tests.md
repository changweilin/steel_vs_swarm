# 真機冒煙清單(手動驗收)

> **本檔定位**:`CLAUDE.md` §5 驗證矩陣的「真機冒煙」欄位抽出後的家。離線稽核 / e2e / bal 驗得到的東西一律不重複列在這裡 —— 這一份只收**只有人眼在真機上看得出來**的項目(2026-08-10 自 CLAUDE.md 抽出)。
> 用法:在 §5 矩陣查到「+ 真機冒煙」時來這裡找對應小節。找不到小節 = 那一項沒有人眼專屬的驗收點。
> 每一條都是**可觀察的結果**,不是操作步驟;括號裡是「壞掉時會看到什麼」。

## 1. 武器 / 傷害 / 命中

### 1.1 填彈與 AoE 彈頭在天上時
- 榴彈 / 巡飛彈 / 雷射導引連打**四五個彈匣**,每一發落地都掉血(病灶從第二個彈匣起才現形,只打一匣一定看不出來)。
- 開完砲收鏡去移動,天上那一輪照樣結算。
- 彈夾數字每扣一次扳機只減 1。

### 1.2 扇形錐緣量到命中量體
- 貼著砲塔或主堡牆面噴電漿 / 散彈,準星壓在牆上**任何一點**都掉血。
- 錐外的敵人照樣打不到。

### 1.3 射速壓縮 / 連發演出
- 機槍扣一次扳機吐出**三發**連續曳光,傷害只結算一次。
- 整條彈鏈聽起來 / 看起來與壓縮前一樣密(打成「一串急促連發 + 一段空白」就是 gap 沒鋪滿週期)。
- 準星上踢與鏡頭震動的節奏與舊制相同;重武器手感逐位元不變。
- 敵方與 bot 的機槍在我畫面上同樣是連發。

### 1.4 開火中位移懲罰
- 手持**最大後座**重武器邊走邊開一砲:人當場定住,約半秒後準星回穩才又能走。
- 機槍連射時走得動但明顯變慢,停火後恢復。
- 低後座輕武器只有輕微拖慢。
- 無人機在空中的同一發只慢一半。
- 打完一發重砲**立刻切輕武器補槍**,那半秒的定身不會提早解除。
- 重砲的向後擊退照樣把人推開;陣亡重生後第一步就是全速。

### 1.5 攻擊範圍收斂 / 爆風家族帶
- 對著同塔位兩座塔中間丟榴彈 / 溫壓火箭 / 152mm / 集束子母彈,**一律只有一座掉血**。
- 榴彈類明顯要走得更近才打得到;雷射導引 / 射後不理的爆風圈比以前大一圈,但仍看得出比榴彈小。
- 導引飛彈 / 巡飛彈仍打得中(沒命中 = `SEEK.R_M` 沒跟著重掃)。

### 1.6 對建築 DPS 收斂
- 任兩把重武器輪流拆同一座塔,秒數不再差到一個量級。
- 反器材 / 微波炮這類過去「打建築像沒傷害」的武器,血條看得出在掉。
- 任何武器拆塔都不再有攻城加速。

### 1.7 護盾分軌剋制
- 反護盾武器打滿盾敵人:護盾條掉得飛快、血條幾乎不動;盾破後換輕武器才磨得動。
- 穿盾武器對滿盾敵人**一定見血**。
- 圖鑑武器列顯示「反護盾 / 穿盾 / 反裝甲」標籤與倍率。

### 1.8 射程光暈 = 這一發的傷害足跡
- 雙方站著不動:**沒有射程光暈的敵人一發都打不掉血、有光暈的必掉血**。
- 榴彈對稜線後方的敵人不亮光暈,繞到側面亮;貼臉導引彈轉琥珀;直擊武器隔牆不亮。
- 準星壓在一群敵人中間的那一個身上,只有**會被這一發炸到的幾個**亮;準星移開落點整組跟著換人。
- 換上步槍只剩準星底下那一個亮;霰彈的錐內全亮;貫穿光束沿線一整排亮。
- beam / missile 武器開火不再整幀卡住。

### 1.9 榴彈火控(準星優先 + 45°)
- 準星壓在地面敵人身上時,旁邊有無人機也**不會**把瞄準點 / 鎖定拉走。
- 對地砲管抬到 45° 且弧高明顯,落點環貼在準星那個部位。
- 準星移到空中單位上立刻轉高速平射。
- 滿射程的敵人打得到(砲彈不在半空自爆);目標走開後砲彈照樣飛完打在原落點。
- 雷射導引同理:碰到就爆、目標閃開就續飛到射程邊界才爆。

### 1.10 射程球心 = 擊發位置
- 用榴彈 / 巡飛彈打接近滿射程的目標,**開完砲立刻往後退**再繼續走位 —— 砲彈落下時血條照樣掉。
- 反過來站在射程外開砲再往前衝,落點照舊零傷害。
- 小隊三機同時後撤時三份傷害都在;重生後第一發不會因為上一條命的位置被誤判。

### 1.11 射後不理追擊 / 爆風擴散
- 鎖定遠方目標後開飛彈,彈頭一路追出射程外並命中。
- 沒鎖定的飛彈仍在射程邊界自毀。
- 榴彈打在射程邊緣時,再外面一點的敵人照樣被濺射傷到。
- 主堡開火不再是瞬發:能看到一顆飛彈真的從砲口飛向目標(與防空飛彈同一顆彈體),飛行途中打得下來(擊落 = 完全否定,不引爆);沒打下來才會在命中時爆炸。

### 1.12 地形稜線遮蔽
- 隔著山稜開散彈 / 電漿 / 貫穿光束,山背後的敵人不掉血。
- 洞內互射照常有效;上橋 / 高地俯射不被誤擋。

### 1.13 直線貫穿的垂直帶換框
- 站在稜線上用反器材砲打山谷裡的砲塔,**血條真的在掉**。
- 洞內對射與平地互轟手感不變。

### 1.14 導引彈只認擊發當下的準星解
- 準星壓著敵人立刻開火,飛彈會追過去。
- 準星移開後開火,彈體**直飛**,不會繞去追先前鎖定的人。
- 開完砲右鍵收鏡照樣算傷害;連打整個彈夾後裝填完打近距目標仍生效。

### 1.15 異常狀態致盲白幕 / 蓄力跳
- 被雷爆彈 / EMP 招式命中:畫面全白後漸淡,HUD 仍讀得到。
- 蓄力跳同蓄力比例跳得更遠,但高度不變。

## 2. 招式 / 大招 / 載具

### 2.1 招式手勢(長按右鍵)
- **一般模式**長按右鍵放的是小招、**狙擊模式**長按放的是大招,兩者與 Q/E 同一份冷卻。
- 十字鍵左的鈕面字是「招式」且冷卻跟著模式換。

### 2.2 招式載具的發射點與 CD 帶
- 一般模式長按:載具 / 輔助機從**自己身邊**冒出來。
- 狙擊模式長按:載具從後方**最近的砲塔或主堡**升空,一路飛過來 —— 沿途看得見、打得下來。
- 小招 CD 明顯拉長到 15~30s。
- 打掉飛過來的大招載具,那一份效果就沒有。
- 機甲連放小招與大招時**兩枚飛彈同時在天上**、都會落地。

### 2.3 大招載具遞送
- t01 長按:飛彈 45° 升空,著彈點打出雪崩齊射的多發爆風。
- s02 長按:四架小機飛向瞄準點,抵達後半徑內友軍裝甲 / 護盾大修 —— 中途被打下兩架就只補一半。
- s03 長按:轟炸機飛抵落點,區內敵人武器離線。
- HUD 不再有機種絕招格;觸控招式鈕在狙擊模式顯示大招 CD([30,60]s)、一般模式顯示小招 CD。

### 2.4 純自身型大招補償
- s11 大修的修復量比改制前明顯多,圖鑑那一行括號標著「含補償 +280」。
- t02 超載期間彈匣打不完,**挨一發立刻恢復正常裝填**。
- m08 匿蹤後開的第一槍傷害暴增約 1 秒。
- s12 大招把倒數中的隊友**原地**拉起來。
- m04 大招期間射程與跑速明顯拉高。

### 2.5 自身強化型 = 跟隨玩家的輔助機隊
- 狙擊模式長按:身邊冒出數架小型輔助機繞著自己飛;加成要等它們**就位那一刻**才上線。
- 打掉對方的輔助機,對方的加成當場變弱;打光就整份消失。
- m08 的輔助機被打下來的瞬間對方**現形**。
- s11 的四架各補四分之一,半路被打掉幾架就少補幾份。
- t02 / t04 那種單機型只有一架,打掉它超載立刻結束。

### 2.6 三種載具形式的彈道
- 飛彈以 45° 斜射出去、畫一條拋物線飛到目標上空,再近乎垂直地**螺旋撲下**;全程看得見 / 打得下來,機首跟著彈道抬頭與低頭。
- 一發飛彈不再把滿血機體直接轟掉,而爆風圈與改制前一樣大。
- 集束炸彈拋物線分別落在**不同**敵人頭上。
- 自殺攻擊機:平時無人機身邊**一架小機都沒有**,長按右鍵那一刻才冒出四架衝出去(左右各兩架散開);自爆後 CD 期間與 CD 結束都不會有機體「重現」在它兩側。

## 3. 機體 / 移動 / 物理

### 3.1 移速壓縮
- 機甲明顯比改制前跟得上無人機,而無人機仍是最快的那一台。
- 變形者飛行型態仍快於自己的地面型態。
- 蓄力跳的水平距離跟著機體速度走。
- bot 的推線速度與真人同機體一致。

### 3.2 飛行動力學
- 被集火時高度一路被壓下來。
- 動力條見底時爬不上去,但仍可平飛 / 下降。
- 地面機甲看不到動力條。

### 3.3 世界高度上限
- 無人機一路往上飛會在某個高度停住,而那個高度**隨場地起伏不同**。
- 觀戰上帝視角同樣升不上去。
- 神木林仍看得出高矮參差、只是整片比改制前矮;巨岩露頭仍是核心大、外圍小。
- 市區最高的樓與砲塔高度比約 4:1;沒有任何建物 / 地標 / 巨岩 / 神木的頂端接近飛得到的天花板。
- **夜裡最高的十幾棟商辦要看得到亮著的窗格**(那幾棟才是整棟量體庫節點)。

### 3.4 世界邊界
- 往任一邊界走:撞上一道**看得見**的連續擋牆 / 土堤 / 岩壁(依地貌換型式),而不是走到某處莫名停住;沿著它走一圈找不到任何縫。
- 牆外看得到的地一路連到地平線,沒有「地突然沒有了」那條硬邊;沿海場地的海面同樣連到地平線。
- 無人機飛過牆頂之後照樣進不去,在同一條線上被擋住。
- 開到底的道路仍在牆內側有車禍 / 施工封路。
- 邊界帶的樓群 / 神木 / 巨岩不會長進牆體裡。
- **邊界牆型錄**(2026-08-11):沿邊界走一圈,牆會**換款** —— 市區段是城牆/連排民房/軍工路障/停駛的列車/連排大貨車/倒塌摩天樓/倒塌高架橋,綠地段是倒塌神木/山崩地/土石流/河堤,裸露地段是懸崖峭壁,水域段是海堤/消波塊/連排貨輪。三件事一起看:
  - 換款的位置對得上地貌與水陸域(**海堤不會出現在山上、城牆不會站在水裡**);
  - **對得上坡度**:陡坡段只有懸崖峭壁 / 土石流 / 山崩地,中等坡再加倒塌神木與城牆(城牆順著稜線一階一階往下走),列車 / 貨車 / 民房 / 高架橋只出現在走得起路的緩坡上;
  - 同一款不會連續鋪超過兩百公尺左右;也不會每隔一節就換一款(碎成拼貼)。
- **城牆的構造**:沿著城牆走,會看到**城門(門是關著的,推不開也走不過去)+ 城樓**、**砲台**(砲口朝圖界外,**不會轉、不會開火、打不到人**)、**箭樓**;素牆段與這三種的高度不同,而**每一段撞到的高度就是看到的高度**(跳到牆前面往上看,牆頂之上沒有看不見的阻擋)。
  - **貼著牆走 + 朝牆開一槍**:看得到的地方都打得到、撞得到 —— 沒有「打得穿卻走不過」或「撞到空氣」的位置;飛到牆頂高度往外斜射,不會有彈道穿過看得見的船樓/塔頂。
- **緩衝空間**:牆外的地是**這張圖自己的地貌繼續延伸**(鏡射拼圖),接縫處看不出色差;那一圈疏疏落落有幾叢林塊 / 岩塊 / 小聚落 / 礁岩,不是一片空地。
- **視線邊界背景**:再往外的天際線有假山(帶雪冠)/ 假森林 / 假城市 / 假海,**方向對得上那一側的地貌**;背景不會近到看起來走得過去,也不會高到穿出天空。

### 3.5 地形坡度移動
- 爬陡坡明顯變慢;峭壁上不去但可沿等高線橫走;下坡加速。
- 上橋引道與洞口不被誤擋。

### 3.6 NPC ⇄ 機體碰撞 / 飛行貼地基準
- 跟著敵方攻擊直升機飛過長橋:**全程貼著橋面上方等高飛**,不會飛著飛著沉到橋面下、也不會鑽進隧道山體。
- 衝刺撞上小兵 / 戰車會被擋在外面而不是穿過去。
- 被小兵擠在牆邊時人停在**牆外**,鏡頭不會穿進牆裡。
- 沒碰到單位時走位手感與改動前一模一樣。

### 3.7 攀爬路線
- 掛梯 / 推杆上下 / 登頂開火 / 跳離 / 箭頭辨識 / 相鄰結構相接各驗一次。
- 長梯 / 抓點頂端**貼著屋頂**不再突出。
- 陡坡山城的建築幾乎棟棟有梯,且梯子一律在**下坡**那幾面;平地街廓仍約三成。

### 3.8 塗層阻擋 / 隧道頂板
- 從山坡走上明隧道 / 落石棚頂板**不再穿模掉進洞裡**,走到簷口才落下。
- 站頂板上朝洞內開火一發都打不到;洞內往上打也打不到站頂板的人。
- 貼著頂板削過去的擦邊彈打在頂板上。
- 洞內通行與洞口進出手感不變。

## 4. 電腦玩家(bot)

### 4.1 視野 / 碰撞
- 繞到 bot 背後它**不會立刻轉身**鎖你,開一槍才轉過來。
- bot 不再從建物 / 砲塔中間穿過去,而是沿牆繞過。
- 高空無人機照樣飛越屋頂。

### 4.2 戰術
- 被集火時 bot 退到**自家塔後面停火**等護盾回滿再上,而不是一路跑回主堡。
- 剩一口氣的敵人會被高難度 bot 丟下手上目標去收掉。
- 高難度 bot 打空彈夾會往後拉開、裝填完再貼上來。

### 4.3 定位分類
- 高難度對局裡看得出四種打法:重甲機甲貼著砲塔硬拆、高速無人機專挑殘血與後排、扇形 / 大範圍機體停在中距離不貼臉、帶團隊治療的機體站最後面且很早就放招。
- **新手 / 低難度手感與改制前完全一樣**。

### 4.4 學習策略
- 高難度 bot 行為與策略檔一致:落地新策略後打帶跑距離環 / 撤退時機看得出變化。
- `--reset` 後回到改制前手感;新手 / 低難度前後完全一樣。

## 5. HUD / UI / 操作

### 5.0 FPV 座艙 / HUD 高度(2026-08-15 使用者四條)
- 座艙裡的機體零件**看得出是這一台**:和第三人稱同一套裝甲/塗裝(舊制那種「通用艙框」已退場)。
  逐機體換角色再看一次 —— 有沒有哪一台的座艙是**空的**(只剩儀表台)。
- **把畫面想成九宮格:正中間那一格一塊零件都沒有**(左右各 1/3、上下各 1/3 的交會處)。
  站定不動、開火、換武器、變形前後各看一次 —— 中間那一格恆空。
- 沒有任何一件大到吃掉視野:最大的那一件(通常是手上那把槍)大約佔畫面的**一個小角**。
- **HUD 下帶不超過畫面高的 1/6**:換不同視窗大小(全螢幕 / 半視窗 / 手機橫式)各看一次,
  下帶跟著等比縮、小地圖仍貼右下角、不會有欄位被切掉。
- **進狙擊模式(右鍵短按)機體零件全部消失**,鏡裡只剩準星與命中/開火回饋;退出後全部回來。
  進出各三次,不可有「某幾件沒回來」;**退鏡那半秒不可以看到放大兩倍的座艙閃一下**。
- **會動的東西動起來也要守規矩**(這一族的壞法在靜止那一幀上完全看不出來):
  - 帶旋翼/螺旋槳的機體(s03 / s11 / m03):槳盤**真的在轉**,而且轉到任何角度都不越過中間那一格與頂緣線。
  - 榴彈機體(s02 / t01 / t11 / m06):準星壓低時砲管跟著抬 —— **槍在原地翹起來**(不是整把槍往畫面中央飄),
    抬到底也不碰中間那一格。
  - 任何機體連打到填彈:退彈匣 / 上掀開膛的那半秒,槍尾不會掀進準星。

## 6. 畫面表現

### 6.1 畫面表現旋鈕 + 樣品
- 設定頁一開就看得到樣品,而且樣品裡的兩個物件都看得到一塊**明顯的暗面**。
- 拉「機體陰影偏色」:左邊那顆球與那截手臂的暗面當場轉藍綠、亮面不動。
- 拉「環境陰影偏色」:右邊那塊岩石與地面跟著轉,而**球不動**(兩軌不得互相影響)。
- 拉「勾線強度」到 0 樣品的黑線消失、拉滿變濃。
- 拉「風化密度」:樣品地面的苔蘚當場由均勻一片變成一塊濃一塊淡(**大廳與戰鬥中都要有反應**)。
- 戰鬥中開設定拉拉桿,關掉選單後戰場畫面就是樣品那個樣子。
- 按「還原預設」四根拉桿一起回位且鈕變灰;關掉設定頁後再開仍記得上次的值。
- 手機直式設定頁不出現橫向捲軸。

### 6.2 景深模糊(只在狙擊模式)
- **一般視角全程銳利**(先確認這個預設狀態沒變)。
- 按右鍵進鏡:遠景隨拉近動畫漸漸散焦 —— 456m 外開始、608m 外糊成一片,而**任何打得到的敵人(含站在塔射程邊緣的)一律全清晰**。
- 放開右鍵模糊跟著鏡頭一起退回去(不得慢半拍)。
- 陣亡與觀戰畫面不得留著模糊。
- 近處機體 / 座艙的輪廓外**沒有**一圈光暈;天際線不出現「糊的地面 / 清晰的天空」硬邊。
- 設定頁「景深模糊」拉到 0% 遠景當場恢復銳利、150% 明顯更糊;樣品裡前排兩件恆清晰、後排三個方塊跟著糊。
- 手機上拉到 0% 幀時要回到這批改動之前。

### 6.3 世界曲面
- 站在開闊地平視:**腳邊到三百公尺完全平坦**,再遠處地面開始沉下去、四百五十公尺左右收成一條地平線。
- 七百公尺外的友軍機體只看得到上半身,砲塔與主堡仍整座看得見;走近它就整台升回來。
- **準星壓在任何打得到的敵人身上都照常掉血**(交戰距離內完全沒有偏移)。
- 雷射 / 貫穿光束仍是一條直線;榴彈拋物線落點與改動前一致。
- 水面遠端不從地形裡浮出來、與岸線接得住;天空與雲不跟著塌。
- 座艙、選角展示台、設定頁材質樣品與改動前一模一樣;`?curve=0` 回到完全平面。

### 6.4 軟性物質(細勾線 + 隨風飄揚)
- 樹冠 / 芒草 / 旗幟隨風擺動,同一片林子是**一波一波掃過去**而不是全體同步點頭。
- 樹幹不動、樹冠動,接合處不開縫。
- 葉叢與草叢的黑線明顯比旁邊的建物 / 岩石細,而**建物的線與改動前一模一樣**。
- 「勾線強度」拉到 0 兩者一起消失,拉滿時軟性仍明顯較細。
- 公園草坪與運動場草皮不再被畫上硬黑邊;花圃會微幅擺動。
- 天上的雲沿同一個風向緩緩漂移並輕微起伏。
- 暫停選單期間草與雲一起停住,回到遊戲一起繼續。

### 6.5 賽璐璐管線
- **幀時 30 秒穩態桌機 + 觸控模擬前後對照** —— 這是唯一決定勾線可不可行的數據。
- `vfx.js` / `castfx.js` / `hazards.js` 的**寫深度透明件**要逐項看過(寫深度的粒子 / 光束 / 貼花在勾線 pass 下會變成斑點)。

### 6.6 表現層資源生命週期
- 真機 60s 連續開火,heap 不單調上升。
- 目視光束粗細(scale 就是半徑)。
