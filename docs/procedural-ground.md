# 程序生成地表與附件

`ground.js` 的 126 種地表與 70 種附件已改用程序生成器。舊地表畫筆與固定附件幾何已移除；地形三角形貼合、分界帶、道路避讓與既有碰撞登記仍由原場景管線處理。沒有下載模型、生成服務或新增 npm 依賴。

## 分類與資料入口

- `public/js/groundCatalog.js`：場域用途、自然景觀、地表分類、尺寸與環境限制。
- `public/js/groundPartCatalog.js`：附件家族、公稱尺寸、顏色、幾何變異範圍，以及各地表的散布／列陣／固定配置。分類中的附件清單由這份配置推導。
- `public/js/proceduralGround.js`：環境解析、選址、尺寸抽樣、表面與文字塗鴉生成。
- `public/js/proceduralGroundParts.js`：葉片、枝幹、岩塊、棚架、家具和工業附件的幾何組裝。

用途分為休憩運動、農牧生產、交通倉儲、產業工程、公共鋪面、森林、草原、裸露地與水域。每個生成場所另記錄緯度、絕對海拔、氣候、溫度、濕度、地質、開局天氣及季節。分類索引由內容表推導。

緯度取場地中心；海拔取 `terrain.elevationAt`，不把遊戲平移後的高度冒充海拔。氣候推估沿用森林系統；可透過 `buildGroundCover` 的 `environment` 指定 climate、temperature、moisture、geology 等資料。正式場景傳入 `cfg.env`。缺乏地質資料時記錄 `unknown`，不聲稱它是真實地質調查。

## 隨機範圍與放置

| 參數 | 範圍／規則 |
| --- | --- |
| 長度 | `2 × (SIZE 基準半徑 + [0, 變幅]) × RSCALE × [0.78, 1]`；沿街陣列使用基準尺寸 |
| 寬度 | 長度乘該地表 aspect，再乘 `[0.7, 1]`；鎖定比例者不乘額外變異 |
| 籃球場比例 | 寬／長固定 `15 / 28` |
| 操場比例 | 由 84.39 m 直線、36.5 m 內半徑、8 × 1.22 m 跑道及外緣空間推導 |
| 直升機坪比例 | 固定 `1` |
| 場所亮度 | `[−0.06, +0.06]`；雨天與秋冬另有環境調整 |
| 散布附件密度 | `[0.6, 1.4]`；零度以下進一步減少 |
| 表面磨耗 | `[0.02, 0.22]`，影響斑駁密度與透明度 |
| 邊緣塗鴉 | 0–3 組；自然地貌沒有人工文字 |
| 附件幾何尺度 | 一般附件公稱尺寸乘 `[0.88, 1.08]`；運動器材固定功能尺寸，只變柱材粗細，再與場地等比縮放 |
| 幾何變體 | 每型 3 組確定性生成原型；座標種子選取，分枝、面板和剪影不同 |

球場、操場、直升機坪容許的全場高差分別為 0.12、0.15、0.12 公尺；水田、魚塭與鹽田也有較嚴格的高差上限。檢查旋轉後的完整足跡，包含角落與內部，取樣間隔最多 2 公尺。超標或高度無效就跳過，不修改權威地形。

自然表面沿用逐頂點地形貼合。附件量測足跡環，避免坡面懸空；矩形硬件在足跡高差超過 0.3 公尺時跳過。籃架沿場地長軸相向放置，長凳沿邊配置，有文字的場所停用 UV 鏡射。

表面開局天氣會改變底色和紋理；戰鬥中動態天氣仍由既有天氣／材質系統控制，不逐幀重新生成貼圖。四季會改變農田和植被筆觸數量，魚塭也有季節漣漪差異。

## 確定性、資源與驗證

地表專屬亂數與座標雜湊不消耗其他場景系統的共享序列。同場地、種子、環境會重建相同結果；原型按塗層合併、實例按變體批次渲染。幾何部署使用副本，貼圖快取限於單次建場。已生成場所的尺寸與分類可在 `group.userData.proceduralSurfaces` 查閱。

```powershell
node test/proceduralGround.mjs
node tools/audit_ground_tile.mjs
node tools/audit_ground_enclave.mjs
node tools/audit_ground_border.mjs
node tools/audit_ground_qc.mjs
node tools/audit_ground_seam.mjs
node tools/audit_client_syntax.mjs
node tools/audit_gpu_lifecycle.mjs
```

幾何測試使用既有 Three.js 0.160 模組；可用 `THREE_MODULE`、`THREE_BUFFER_UTILS` 指定路徑。GPU 預覽執行 `node test/proceduralGroundPreview.mjs`，另需現有 Playwright（`PW_MODULE`）與 `THREE_PASS`。預覽使用遊戲後製管線，輸出 `out/ground_review/procedural-ground.png`。


## 運動與地域擴充

新增 24 種運動用途：網球、羽球、匹克球、排球、沙灘排球、足球、五人制足球、手球、曲棍球、橄欖球、美式足球、籃網球、板球、棒球、壘球、卡巴迪、藤球、法式滾球、義式滾球、門球、相撲、摔角、射箭、跳遠。連同原有籃球與跑道，共 26 種運動用途。

新增 8 種地域場域：臺灣廟埕、日本枯山水、華人庭院、地中海噴泉廣場、北非中庭、拉丁美洲市集廣場、南亞公共活動空地、北歐公共廣場。文化標籤供分類瀏覽，表示設計來源，不是國界限制；目前在都市候選池抽樣，不以緯度猜測國家。庭院與廣場保留集會空間，配香爐、燈籠、石燈、噴泉、市集棚架等用途附件。

`groundVenues.js` 是尺寸、文化標籤、用途與附件錨點的共同資料來源；`groundMarkings.js` 依功能繪製標線。場地均保持比例並通過全場平地檢查，按遊戲地圖空間等比縮放；大型球場並非實際公尺大小，也不是競賽認證施工圖。標線為遊戲可辨識的主要規則線，未窮盡各聯盟、年齡與競賽版本，例如手球替補區、美式足球逐碼短標及各田徑起跑錯位線未細畫。

球網、球門與標線共用場地縮放比例。附件不能獨立拉伸；專用場地關閉隨機貼圖鏡射，避免非對稱設備與標線相反。操場外形由兩條直線與兩個半圓拼接，跑道寬度一致。無通用裝飾網格；只有停車格、磚縫、種植壟、球場規則線與真正球網保留規律線條。體育區不塗隨機文字或塗鴉。

- [FA／IFAB 足球場地](https://www.thefa.com/football-rules-governance/lawsandrules/laws/football-11-11/law-1---the-field-of-play)：足球禁區與角球區。
- [MCC pitch law](https://www.lords.org/MCC/The-Laws-of-Cricket/The-pitch)：板球中央投球區尺寸。

## 綠地、裸露地與外圈跑道可見度

`groundLandscapes.js` 新增 10 種綠地（苔蘚、三葉草、蕨類林下、石楠灌叢、高草草原、稀樹草地、高山花甸、濕草甸、河岸灌叢、海岸草叢）及 10 種裸露地（玄武岩碎地、火山灰、白堊、風紋沙地、礫石灘、鹽殼、乾湖床、侵蝕黏土、冰磧、鐵質碎石）。加入綠地／裸地特徵候選池與家族延伸；高山、河岸項目另接對應候選區。連續底毯仍沿用既有選款規則。

新地表以不規則色塊貼合起伏，搭配現有程序生成附件；有專屬草葉、苔斑、角礫、風紋、裂紋等紋理。高山、寒地、熱草地及海岸項目依海拔或溫度排除不適合的位置；名稱是生成樣式，並非真實地質判定。

跑道外緣草帶由 4 增至 12 個參考長度單位，整體長寬比同步推導；外圈筆畫在兩軸均保留超過 5% 貼圖安全邊距。跑道貼圖提高至 1024 像素，規則線為可讀性略作視覺加粗，避免細線縮小後消失。八道跑道保留兩直線、兩半圓構造；外圈不貼齊矩形裁切邊界。測試涵蓋外圈筆畫完整包覆、新地表坡面適應與正式部署。


## 綠地與裸露地的人造／觀光配對

以本輪系列擴充的 `LANDSCAPES` 自然場地為計數範圍：綠地 10 種自然＋10 種人造／觀光；裸露地 10 種自然＋10 種人造／觀光。既有農田、工業地與都市場域未混入這個新增配對統計。`groundVisitorSites.js` 的 `naturalCounterpart` 建立一對一關係，測試檢查各區數量相等且無重複配對。

綠地新增：苔庭休憩區、草坪野餐區、林下自然教室、石楠花園步道、草原露營區、草原導覽休息站、高山步道休憩點、濕地解說廣場、河岸野餐休憩地、海岸步道休息站。

裸露地新增：玄武岩戶外展示場、火山地質導覽站、白堊地步道入口、沙地營地、礫灘休憩廣場、鹽地文化解說場、乾湖觀星集合地、陶土戶外體驗場、冰磧地觀景休息點、礦業遺產展示地。

新增程序生成野餐桌、帳篷與垃圾桶；其餘使用既有長凳、解說牌、棚架、花器及展示石等。通行路徑與附件共用錨點，固定貼圖朝向，避免鏡射錯位。人造場域採固定比例與全場 0.25 m 高差上限，繼承對應自然場地的溫度／海拔限制；找不到適合位置就省略。數量相等指可生成種類數，不保證每場地圖的實際放置數相同。
