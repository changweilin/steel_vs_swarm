# 船隻生成與装載設計

`vesselCatalog.js` 定義相容分類、材質與尺度；`vesselLayout.js` 定義每款船的船體／船艙、裝載區與隨機設備；`vesselModels.js`、`vesselEquipmentModels.js` 依同一份配置建模。全部為背景表現，未新增武器傷害、彈藥或戰鬥 AI。

## 裝載參數與限制

每個裝載區有允許的種類、格位、最小／最大占用數、底面高度與層數。種子同時決定種類、數量、格位、顏色和 VLS 格數。數量受空間容量限制；未占用格保留通道。所有模型的砲管、吊臂、機翼與旋翼都須完全落在其預留包圍盒內。

- 貨櫃使用 2.44 × 12.19 × 2.59 m 的 ISO 尺度，一至三層，最多 40 堆；標準、冷藏、罐式貨櫃混裝，逐層從底部支撐。
- 散貨有煤炭、礦砂、穀物及封艙蓋；雜貨包含木箱、原木、鋼捲、鋼管和工程機具。
- 油輪使用管匯和甲板管線；LNG 分為球罐與薄膜罐罩，不把油輪畫成外露 LNG 圓罐。LNG 三至五座艙罩。
- 科研工作甲板位於前置駕駛艙後方，混合 CTD、ROV、浮標、絞車和實驗艙；船尾保留 A 架，雷達／衛星罩裝在艙頂。
- 軍艦配置艦砲、機砲、近防砲、VLS、斜置飛彈、防空飛彈、魚雷及誘餌。巡邏艇依長度限制三至五座輕武器，避免小艇過載；飛彈快艇不使用大型 VLS 配置。每組 VLS 有 8、12 或 16 格。
- 航母有右舷艦島、舷外防禦武器及七至十四架展示飛機；飛行走道獨立保留。舷側武器朝外，艉部武器朝後。此為有界的遊戲展示數量，不代表滿編艦載機數。
- 獨木舟有實際開口、座椅、低舷與槳；充氣艇有浮筒、抓把和舷外機，不加鋼板鏽斑或大型船艙。開放船採微高於水面的淺底座艙，避免共用水面穿過座艙地板。

## 接線與驗證

場景保留最多三艘巡航船、八艘停泊船、一艘研究潛器的預算。甲板寬納入選址範圍；水深或航道不足則略過。大航母、長貨輪不會硬塞進小地圖。航域分類供篩選，仍未由地理資料自動判別內海／湖泊，也未加入破冰或畜力拖船物理。

圖鑑：啟動 `node server/server.js --port 8621` 後開啟 `/public/vessels.html`，選船型與種子，下方顯示實際材質及裝載數。

```powershell
$env:THREE_MODULE = "C:\path\to\three.module.mjs"
node test/vessels.mjs
node tools/audit_aquatics.mjs
node tools/audit_client_syntax.mjs
node tools/audit_gpu_lifecycle.mjs
```

測試包含 43 船型 × 100 種子配置、全部設備可達性、裝載格位互斥、艙室／起降區淨空、堆疊支撐，及每船三個種子的真實 Three.js 幾何包圍盒、預算、尾波與回收。
